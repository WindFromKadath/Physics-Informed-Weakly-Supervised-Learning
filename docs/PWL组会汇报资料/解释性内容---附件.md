# 解释性内容——附件

> 用途：作为《PWL项目全景介绍》PPT的讲解补充材料。重点解释基函数为什么要拆分、它与完整代数方程的关系，以及项目如何从论文仿真迁移到 COMSOL 热传导场景。

## 1. 一句话先解释：基函数是什么

基函数可以理解为一组“可复用的基本模式”。复杂的模型输出，不再只被看作一个不可拆开的整体，而是写成多个基本模式的加权组合：

\[
f(x) = \sum_{j=1}^{M} w_j\,\phi_j(x)
\]

其中：

- \(\phi_j(x)\)：第 \(j\) 个基函数，表示一种基本变化模式；
- \(w_j\)：该模式的权重，表示它在当前样本中的作用大小；
- \(M\)：基函数数量，决定模型能够表达多少种变化模式。

一个非常简单的例子是：

\[
y = 2 + 3x - 0.5x^2
  = 2\cdot 1 + 3\cdot x - 0.5\cdot x^2
\]

这里 \(1\)、\(x\)、\(x^2\) 就可以看作三个基项。基函数拆分并不是凭空改变原来的函数，而是把原本写在同一条公式里的不同作用拆开，使它们能够被分别观察、加权、筛选和校正。

给听众的直观说法可以是：

> 完整公式像一台已经组装好的机器；基函数像机器中的若干部件。机器可以直接工作，但如果我们想知道哪个部件负责什么、哪个部件需要校正，或者想在保留物理结构的同时加入数据修正，就需要能够访问这些部件。

## 2. 为什么不直接使用完整代数方程

完整代数方程当然可以直接使用，项目中的 PhysicsDirect 就承担了这个对照角色。问题不在于完整方程“不能用”，而在于它不适合作为当前 PWL 框架中的可学习接口。

### 2.1 完整方程的优点

如果完整方程已经准确、参数已经确定，那么直接计算最简单，也最容易解释：输入代入公式，输出直接得到。

### 2.2 完整方程在迁移和校正中的限制

当研究对象从论文中的仿真场景迁移到新的物理场景时，完整公式通常会遇到几个问题：

1. **物理结构和误差结构混在一起。** 公式中既有希望保留的物理规律，也有与当前仿真网格、边界设置或参数标定有关的误差。
2. **无法单独调整某一种变化模式。** 如果某个局部变化趋势不匹配，直接改整条公式容易破坏原有结构。
3. **难以做稀疏选择。** 在低数据量场景中，并不是所有候选项都值得保留；完整公式不便于对单个项做选择或正则化。
4. **不便于区分“物理参数”和“差异补偿”。** PWL 需要将物理分支与差异分支分开，从而判断预测改进来自物理解释还是来自经验修正。

所以，基函数拆分的核心目的不是“替代公式”，而是把公式变成一个可校正、可学习、可迁移的模型接口。

## 3. PWL 中的 H/B/θ 分工

在本项目的表达中，可将预测写成如下结构：

\[
\hat y = H(x_{ph},\theta)\,g + B(x_{pr},x_{ph})\,d
\]

其中：

- \(H(x_{ph},\theta)g\)：物理分支。\(H\) 由物理输入和物理参数生成，\(g\) 是物理基函数权重；
- \(B(x_{pr},x_{ph})d\)：差异分支。\(B\) 表示物理模型与真实数据之间的可学习补偿，\(d\) 是差异基函数权重；
- \(x_{ph}\)：物理输入，例如热流、换热条件、环境温度等；
- \(x_{pr}\)：实际工况或实验/迁移输入；
- \(\theta\)：物理参数或校准参数，在项目中也应谨慎理解为“模型参数”，而不自动等同于真实材料常数。

因此，基函数拆分至少提供了三个能力：

- 保留一部分已知物理结构；
- 用差异基函数表达物理模型没有覆盖的部分；
- 在求解过程中对不同模式进行独立的权重控制和正则化。

## 4. 这种分解是否在论文中有依据

有依据，但需要区分“论文明确提出的结构”和“当前项目的工程实现”。

### 4.1 论文明确给出的内容

论文正文的公式 (3)–(5) 已经将模型拆分为物理模型项与差异项，并通过基函数/特征矩阵表达这两部分。补充材料中的 Proposition 1–3 则进一步说明了相关表示、可识别性或求解结构的条件。

因此，以下结论可以归属于论文方法本身：

- 物理模型与差异模型需要分开表达；
- 两部分可以分别构造特征/基函数矩阵；
- 系数可以通过受约束的优化或线性代数步骤求解；
- 分解有助于表达物理蒸馏、差异补偿和弱标签校正。

### 4.2 论文没有限定的内容

论文并没有规定当前项目必须使用某一套唯一的基函数库，也没有把项目中的每个具体特征数量、分箱方式或迁移变量组合全部写死。因此，以下内容属于项目对论文框架的工程化实例化：

- 当前使用的物理特征和差异特征清单；
- 特征分箱、归一化和截断规则；
- COMSOL 热传导场景中的具体输入映射；
- 训练批次、测试批次、重复实验和统计汇总方式。

讲解时建议使用如下表述：

> 论文给出了“为什么要分成物理分支和差异分支”的方法依据；本项目进一步把这一思想落到具体基函数库、特征注册和 COMSOL 输入映射上。后者是复现与迁移阶段的工程实现，不应表述成论文原文逐项规定的内容。

## 5. 为什么基函数拆分适合低数据量场景

如果数据量很大，复杂模型可以用大量自由度去拟合输入与输出关系。但在本项目的设定下，样本量有限，更重要的是控制自由度和保留可解释结构。

基函数拆分后可以：

1. 用物理分支提供主要趋势，降低差异模型需要学习的难度；
2. 通过正则化或稀疏约束，压低不重要模式的权重；
3. 通过分组选择，让一组具有共同物理含义的项一起进入或退出；
4. 将“模型结构错误”和“参数标定错误”暴露为不同的可检查部分；
5. 在迁移到新场景时，只替换输入映射和必要的基函数，而不必重写整个学习框架。

这也是为什么 PPT 中不只展示一个最终误差数字，而要同时展示特征注册、优化器、H/B 分支和迁移输入的原因。

## 6. COMSOL 热传导迁移中的具体实现解释

项目在论文仿真复现之后，转向 COMSOL 热传导迁移。这里的重点不是声称所有论文实验都已经在同一个工具链中完整重做，而是展示 PWL 框架如何映射到新的物理场景。

一个便于讲解的映射如下：

| PWL 角色 | COMSOL 热传导中的示例含义 |
| --- | --- |
| \(x_{ph}\) | 热流、换热系数、环境温度等物理输入 |
| \(x_{pr}\) | 当前工况、位置或观测条件 |
| \(\theta\) | 导热系数等待校准/标定参数 |
| \(H\) | 由热传导物理关系构成的基函数矩阵 |
| \(B\) | 用于描述 COMSOL 结果与简化物理模型之间差异的特征矩阵 |
| \(y\) | 观测位置的温度或温度场统计量 |

PPT 中的热传导示意图只用于帮助听众理解“热流—界面—测量”的关系，不代表具体网格、边界条件或实验结果。真实结果应以项目脚本、COMSOL 模型文件和导出的数据为准。

当前汇总结果可以这样谨慎表述：

- 在统一测试协议下，PWL 的平均误差为 5.351，Physics-GP 为 5.648；
- 12 个测试批次中，PWL 有 12/12 次更优；
- 配对检验的原始 p 值为 0.036，但经 Holm 校正后为 0.071；
- 因此应说“观察到稳定的平均优势趋势”，不宜说成“多重比较校正后仍显著优于对照”。

## 7. 听众常见问题与建议回答

### 问：基函数是不是把原来的物理公式改错了？

答：不一定。若权重固定且基函数完整，基函数组合可以等价表示原公式。拆分的目的，是让物理结构、差异补偿和可学习系数分别暴露出来。完整公式仍作为 PhysicsDirect 对照保留。

### 问：为什么不直接把所有变量放进一个神经网络？

答：当前项目要验证的是物理引导、低数据量和可解释校正，而不是追求一个黑箱拟合器的最大容量。PWL 的优点是能回答“哪一类物理模式有效”“差异补偿有多大”“参数改变影响哪一部分”。这并不意味着神经网络不能使用，而是研究问题不同。

### 问：为什么物理参数放在 H 分支，而不是放在 B 分支？

答：因为 \(H\) 负责表达物理模型本身，物理参数应该改变物理分支的形状或尺度；\(B\) 主要描述物理模型与真实数据的差异。如果把物理参数直接放进差异分支，容易把物理误差和经验补偿混在一起，解释性会变差。

### 问：H 和 B 会不会表达重复的内容？

答：会有潜在的可识别性问题，所以需要在特征设计、正则化、分组约束和残差化处理上做控制。实际实现中应检查特征相关性、矩阵条件数和不同初始化下的解稳定性，不能只看最终测试误差。

### 问：拟合出来的 θ 就是真实材料参数吗？

答：不应自动这样解读。在 COMSOL 迁移中，θ 更稳妥的说法是“用于校准物理分支的模型参数”。只有在参数可识别性、边界条件、单位、尺度和观测噪声都得到独立验证后，才有资格进一步讨论它是否接近真实材料常数。

### 问：基函数越多是不是越好？

答：不是。基函数越多，自由度越大，可能导致共线性、过拟合和 H/B 之间的归因混乱。更合理的原则是：先用少量具有明确含义的候选项，再通过消融、正则化、条件数和跨批次稳定性决定是否增加。

## 8. PPT 讲解顺序建议

1. 先用第 8 页的图说明“完整曲线可以由多个基本模式重新组合”；
2. 再强调“完整公式能直接用，但不便于逐项学习和校正”；
3. 用 H/B/θ 解释物理分支、差异分支和校准参数的角色；
4. 用第 9 页图说明这些抽象角色如何映射到热传导迁移；
