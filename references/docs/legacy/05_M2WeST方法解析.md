# 05 文献解析：M2WeST —— 多源多任务弱监督迁移学习（学位论文第 4 章）

> **原文**：Alenezi, D. (2024). *Multi-source Multi-task Weakly Supervised Transfer Learning for Telemonitoring of Parkinson's Disease*. 见博士学位论文第 4 章（p.86–131），附录 B（p.145–153）；期刊版本 "in preparation"（撰写时未发表）。
>
> **对应文件**：`ALENEZI-DISSERTATION-2024.pdf`
>
> **在文献体系中的位置**：三部曲的**集大成者**——把 [01_RWSL](01_RWSL论文解析.md) 的排序弱监督从"单患者"推广到"多患者"，并与迁移学习/多任务学习融合。

## 1. 基本信息与动机

| 项目 | 内容 |
|---|---|
| 方法名 | **M2WeST**（Multi-source Multi-task Weakly Supervised Transfer Learning） |
| 应用 | PD 远程监护：用 mPower 敲击/语音数据预测 MDS-UPDRS |
| 直接前辈 | RWSL（第 2 章）、迁移学习（Pan & Yang, 2010）、多源迁移 MSTL |

### 1.1 三个待解决的挑战

1. **标签稀缺**（同 RWSL）：MDS-UPDRS 每月才有，活动数据每天多次 → 每个患者的 (X, Y) 对很少；且自评量表有主观偏差、回忆偏倚；
2. **患者异质性**：PD 症状/病程/药物反应因人而异 → 直接合并多患者数据会产生**负迁移（negative transfer）**；
3. **现有方法的局限**：
   - RWSL：只用单患者数据，且仅限有药物信息且药物响应显著的患者；
   - 迁移学习：假设每个源域有足够标签，且多为**单源**设计；
   - 多源迁移（MSTL）：假设源间同质、依赖源域充足标签、多患者信号可能相互冲突。

### 1.2 问题设定

- **目标患者 t**：标记数据 (X_l^t, Y_l^t)（N_l^t 个）、无标签数据 X_u^t；由领域知识构造**排序对集 Ω_w^t**：对 (x_p^t, x_q^t) ∈ Ω_w^t 有 y_p^t ≥ y_q^t（式 26，如服药前/后）；
- **源患者 s ∈ {1,…,S}**：同样有标记数据 (X_l^s, Y_l^s)、无标签数据 X_u^s、排序对集 Ω_w^s；
- **目标**：融合目标 + 多源的标记/弱标签数据，预测目标患者的严重度 Y^t。

### 1.3 四大贡献（作者自述）

1. **多数据类型**：强学习任务（标记数据）+ 弱学习任务（排序对）的统一形式化；
2. **多异质数据源**：每个源患者独立参数集，保留个体差异，抗负迁移；
3. **算法**：针对非凸模型的 BCD-ADMM 高效求解；
4. **实证**：仿真 + mPower 两个真实案例（敲击、语音）验证优越性。

## 2. 方法论

### 2.1 模型组件（式 27–30）

| 组件 | 公式 | 说明 |
|---|---|---|
| 目标患者**排序损失**（式 27） | λ_w^t/\|Ω_w^t\| · Σ max(0, 1−(f_β(x_p^t)−f_β(x_q^t))) + ½\|β\|² | hinge 排序损失（源自 SVMRank / RWSL）+ L2 间隔最大化 |
| 源患者**监督损失**（式 28） | (1/N_l^s) Σ ‖y_j^s − g_θs(x_j^s)‖² | 每个源患者独立参数 θ_s |
| 源患者**排序损失**（式 29） | λ_w^s/\|Ω_w^s\| · Σ max(0, 1−(g_θs(x_k^s)−g_θs(x_m^s))) + ½\|θ_s\|² | 源患者也用弱标签 |
| **特征增广函数** | h(x) = [x, g_θ1(x), …, g_θS(x)] | 把所有源模型的预测作为新特征注入目标模型——多源知识的载体 |
| 目标患者**监督损失**（式 30） | (1/N_l^t) Σ ‖y_i^t − f_β(h(x_i^t))‖² | 在增广特征空间上训练 |

### 2.2 统一优化目标（式 31）

$$\min_{\beta,\theta_1,\dots,\theta_S} \; \underbrace{\tfrac{1}{2N_l^t}\textstyle\sum_i\|y_i^t - f_\beta(h(x_i^t))\|^2}_{①\ 目标监督} + \underbrace{\tfrac{\lambda_t^w}{|\Omega_t^w|}\textstyle\sum_{(p,q)}\max(0, 1-(f_\beta(h(x_p^t)) - f_\beta(h(x_q^t))))}_{②\ 目标排序} + \underbrace{\lambda_t^1|\beta|_1 + \tfrac{\lambda_t^2}{2}|\beta|_2^2}_{③④\ 弹性网正则}$$
$$+ \sum_{s=1}^{S}\Big[\underbrace{\tfrac{\lambda_s^l}{2N_l^s}\textstyle\sum_j\|y_j^s - g_{\theta_s}(x_j^s)\|^2}_{⑤\ 源监督} + \underbrace{\tfrac{\lambda_s^w}{|\Omega_s^w|}\textstyle\sum_{(k,m)}\max(0, 1-(g_{\theta_s}(x_k^s)-g_{\theta_s}(x_m^s)))}_{⑥\ 源排序} + \underbrace{\tfrac{\lambda_s^2}{2}|\theta_s|_2^2}_{⑦\ 源 L2}\Big]$$

设计逻辑：
- ①⑤：强监督任务——精确预测（目标/各源）；
- ②⑥：弱监督任务——相对排序（目标/各源）；两任务**共享参数空间** → 多任务学习；
- ③ L1 稀疏 → 特征选择、抑制增广特征中的冗余源；
- h(x) 使目标模型吸收多源模式而不强迫源间同质 → 迁移学习；
- 问题**非凸** → BCD 分解。

### 2.3 算法（Algorithm 3：BCD-ADMM）

- f_β、g_θs 取**线性映射**（实践中效果满意）；
- hinge 损失换 **Huber 损失** L_huber(t) = max(0,1−t)² − max(0,−t)²（同 RWSL 的处理）→ 凸、光滑；
- **循环**：① β 更新（凸，ADMM，M=3：f₁ 最小二乘 / f₂ Huber 排序 / f₃ 弹性网）；② θ_s 更新（凸，ADMM，M=3）；直到目标残差 < ε0；
- **初始化**：β 用目标患者纯监督模型初始化；θ_s 用各源患者纯监督模型初始化；
- **近端算子**（附录 B，Proposition 4/5）：
  - prox(最小二乘)：(I + (Δ/N)(H^l)ᵀH^l)⁻¹(v + (Δ/N)(H^l)ᵀY)——闭式；
  - prox(Huber 排序)：三段式（v≥1 不惩罚；0≤v<1 二次区缩放；v<0 线性区平移）；
  - prox(弹性网)：S_{Δλ₁}(v)/(1+Δλ₂)（软阈值 + 收缩）；θ_s 的 f₃ 仅 L2 → v/(1+Δλ₂^s)。

### 2.4 工程与理论保障

**(a) 超参数优化**：用 **Optuna**（TPE 自适应采样 + 剪枝），以验证集 MSE 自动搜索 6 个 λ。

**(b) 源患者预选（Algorithm 5）**：源很多时先筛选，防负迁移、降计算量。对每个源 s 计算**组合势**：
- 精度势：源模型 g_s 在目标标记数据上的 MSE（min-max 归一化）；
- 相关性势：g_s 与其它源模型预测的相关性（冗余度）；
- P_a = −γ₁·MSE_a − γ₂/(S−1)·Σ_{b≠a} Corr(g_a, g_b) → 按 P_a 排序取 **Top-K**（既准又互补）。

**(c) 理论性质（Proposition 6，单源情形泛化界）**：
- 设源任务 g_θs 的风险界为 O(1/(N_l^s)^{γ_s})，损失 ℓ 关于参数 L′-Lipschitz；
- 则目标任务的**超额风险**：

$$\mathbb{E}[\ell(f_\beta(h(x)), y^t) - \ell(f^*(h(x)), y^t)] = \mathcal{O}\Big(\frac{d\gamma_s\rho\log(RL'N_l^t) + \log(1/p)}{N_l^t} + \frac{L'}{(N_l^t)^{\gamma_s\rho}}\Big)$$

  以概率 ≥ 1−p 成立，条件是 **N_l^s = Ω((N_l^t)^{2ρ})**；ρ 为源-目标相关度因子；
- **含义**：源样本足够多、源与目标足够相关时，特征增广 h(·) 能降低目标任务的泛化误差——为"迁移有益"提供了理论保证；
- 证明路线（附录 B.3）：超额风险分解（源贡献 + 目标贡献）→ 弱中心条件（连续标签版）→ 目标域泛化界，沿用 Robinson et al. (2020) 的命题 6/8/9 与定理 10；排序损失视为额外正则，未显式入界。多源情形的形式化留作未来工作。

## 3. 仿真实验

### 3.1 设置

- 目标患者：β ~ N(μ_β, Σ_β)（μ_β 为全 1 向量）；源患者：**θ_s = β + η_s**，η_s ~ N(0, σ_{δ1}²I)，**δ1 控制患者间差异度**；
- 特征：20 个相关特征 Z1 + 5 个噪声特征 Z2；Y^t = Z1^t β + ε；Y^s = Z1^s θ_s + ε；SNR 控制噪声；
- **100 个源患者**；弱标签：按 |y_p − y_q + ε_{δ3}| ≥ threshold（阈值 > σ_noise）构造排序对，ε_{δ3} ~ N(0, σ_{δ3}²) 为弱标签不确定性；
- **对比模型**（6 个）：
  - SL（单学习，ridge，仅目标标记数据）；
  - TrAdaBoost（迁移提升，需源域全标签）；
  - CORAL（相关对齐，域偏移）；
  - Mean Teacher（半监督，仅目标）；
  - RWSL（仅目标弱监督）；
  - ATBTL（适应性树提升多源迁移）；
- 指标：MSE、RMSE、预测相关性。

### 3.2 四组实验结论

| 实验 | 变量 | 结论 |
|---|---|---|
| 4.4.1 预测性能 | 50 标记 + 1000 排序对/患者 | **M2WeST 全面最优**（MSE/RMSE 最低、相关性最高、方差最小）；RWSL、ATBTL 次之但波动大；SL、CORAL 最差 |
| 4.4.2 源-目标相关度 | δ1：相关度 1（最不相关）→5（最相关） | 所有模型随相关度上升而改善；**M2WeST 在所有水平都最低**——异质性高时它加大目标自身弱监督权重，规避负迁移 |
| 4.4.3 源不确定性 | 源域标记样本 100→20（5 场景） | M2WeST 全程最优；源标签越少（场景 4、5）差距越大——它可借助源域**排序弱标签**补偿标签不足；CORAL 退化最严重 |
| 4.4.4 弱标签不确定性 | δ3 五档递增 | M2WeST 的 MSE 几乎平稳（可转而依赖强标签）；**RWSL 急剧恶化**——其对弱标签质量高度敏感 |

## 4. 真实数据应用（mPower，两个案例）

### 4.1 数据与预处理

| | 敲击（tapping） | 语音（voice） |
|---|---|---|
| 任务 | 两指交替敲屏 20 秒，每日 3 次（服药前/后/其他） | 持续发 "aaaah" ≤10 秒 |
| 特征 | **43 维**（敲击次数、平均/中位敲击间隔等） | **339 维**（shimmer 振幅扰动、jitter 频率扰动、信噪比等） |
| 患者筛选 | 服药前/后各 ≥30 次任务 + 药物响应显著（同 RWSL 流程） | 同左 |
| 标记样本 | **558**（MDS-UPDRS 线性插值） | **496** |
| 无标签 | 服药前 2,784 + 服药后 2,299 | 服药前 2,695 + 服药后 2,137 |
| 排序对 | **31,458** | **29,992** |
| 响应 | MDS-UPDRS（0–64） | 同左 |

### 4.3 失败/成功原因分析（论文原文洞察）

- **TrAdaBoost、CORAL**：不处理患者间差异 → 负迁移，甚至差于 SL；
- **Mean Teacher**：仅用目标患者无标签数据，无弱监督、无多源 → 提升有限；
- **SL**：无负迁移但也无多源/弱监督红利；
- **RWSL**：受益于弱监督，但无法用其他患者数据，仅限弱数据显著的患者；
- **ATBTL**：受益于多源，但缺弱监督机制，难以利用"标签极少、无标签极多"的患者；
- **M2WeST**：弱监督 × 多源的平衡整合——既避开异质患者的有害信息，又充分利用标签极少患者的数据 → 最鲁棒。

## 5. 局限与未来方向

1. 弱标签生成目前基于"药物效应"单一准则 → 可纳入更多患者特异性特征；
2. 未建模时间维度 → 引入时序数据实现动态病程追踪；
3. mPower 为受控研究数据 → 真实世界（缺失、不依从、自评偏差）泛化需鲁棒预处理；
4. 临床应用前需设计完善的临床试验验证，与医生评估对齐以建立信任。

## 6. 关键贡献小结

1. **概念**：首个将"排序弱监督"与"多源迁移学习"统一于同一参数空间的框架，弱标签同时存在于目标域与源域；
2. **机制**：特征增广 h(x)=[x, g_θ1..S(x)] + 源预选算法（精度/冗余双准则）→ 抗负迁移；
3. **算法**：非凸问题的 BCD-ADMM 求解，全部子问题凸且近端算子闭式；Optuna 自动调参；
4. **理论**：单源情形超额风险界（Proposition 6），给出迁移有益的样本条件 N_l^s = Ω((N_l^t)^{2ρ})；
5. **实证**：仿真 4 实验 + mPower 双案例（敲击/语音）对 6 个基线全面胜出，且在源异质、源标签稀缺、弱标签噪声三类恶劣条件下最稳健。
