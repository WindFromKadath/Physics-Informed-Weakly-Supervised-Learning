## 2. 研究背景与问题定义

### 2.1 应用背景：PD 远程监护

- **帕金森病（PD）**：全球患者 700–1000 万，美国每年花费约 520 亿美元，无法治愈但可通过药物控制症状；有效控制需要**频繁监测**以调整药物、物理治疗和脑深部刺激设备。
- **传统评估方式**：每 4–6 个月一次门诊（资源匮乏地区更少），使用 MDS-UPDRS 量表（1987 年 UPDRS 的 2007 修订版，金标准）→ 评估稀疏、干预延迟。
- **远程监护（Telemonitoring）**：通过手机 App（如 **mPower**，基于 ResearchKit）引导患者完成敲击（tapping）、发声、行走等活动，利用手机传感器（加速度计、陀螺仪、麦克风、触屏）高频采集数据，成本几乎为零。

### 2.2 数据挑战（核心矛盾）

1. **标签稀缺**：活动数据 X 每天可采集多次，但疾病严重度 Y（MDS-UPDRS）最多每 4–6 个月评估一次 → 匹配的 (X, Y) 样本极少。
2. **数据质量差**：患者自我管理（self-administered），存在不依从、误操作导致的缺失。
3. **辅助信息未利用**：mPower 还采集服药时间等信息，但如何用于增强模型训练是开放问题。

### 2.3 核心洞察（领域知识 → 弱标签）

> PD 的多巴胺能药物可在短时间内缓解症状。因此同一患者**服药前**采集的样本 xi 与**服药后**采集的样本 xj 可排序为 **yi ≥ yj**（服药前更严重），尽管 yi、yj 的精确值未知。

这种"只知相对序、不知精确值"的样本称为**排序样本（ranked samples）**。RWSL 的目标：**融合少量标记样本 + 大量排序样本**，训练一个用 X 预测 Y 的回归模型。

### 2.4 在弱监督学习谱系中的定位

按 Zhou (2018) 的分类：WSL 分为 incomplete（不完全）、inexact（不精确）、inaccurate（不准确）监督。RWSL 属于 **incomplete supervision**（仅部分样本有标签），与半监督学习（SSL）同族，但区别在于：SSL 假设无标签样本的 Y 完全未知，RWSL 则利用领域知识获得 Y 的**弱标签信息（相对排序）**。

与信息检索（IR）中 learning-to-rank（pointwise / pairwise / listwise）的区别：

| | IR learning-to-rank | RWSL |
|---|---|---|
| 目标 | 对文档排序（满足序约束即可） | **精确预测响应变量 y** |
| 特征角色 | 用于判断文档与查询的相关性 | 用于解释与 y 的关系 |
| 数据 | 仅有排序信息 | **排序样本 + 标记样本联合训练** |

## 3. 方法论

### 3.1 模型形式化

- 标记样本：{xl, yl}，l = 1…L（共 |L| 个）
- 排序样本对：{xi ≻ xj}，(i,j) ∈ Xd（共 |Xd| 对），"≻"表示 yi ≥ yj，由准则 d（domain knowledge）产生
- 目标：学习 f(x)，使对任意排序对满足 f(xi) − f(xj) ≥ 0（正的间隔）

借鉴 **SVMRank** 的间隔最大化思想，同时叠加监督学习项，RWSL 的原始形式（式 2）：

$$\min_b \; \frac{1}{2}\|b\|_2^2 + \frac{\lambda_L}{2|L|}\sum_{l=1}^{|L|}\|y_l - f_b(x_l)\|_2^2 + \frac{\lambda_R}{|X_d|}\sum_{(i,j)\in X_d}\eta_{ij}$$
$$\text{s.t. } f_b(x_i) - f_b(x_j) \ge 1 - \eta_{ij},\quad \eta_{ij} \ge 0,\; \forall (i,j)\in X_d$$

三项含义：

1. **‖b‖²/2**：最大化排序样本间最近距离（1/‖b‖），提升对 x 噪声的鲁棒性（泛化）；
2. **二次损失**：使标记样本预测值贴近真实 y；
3. **松弛变量 ηij 之和**：软排序约束，允许少量样本被错误排序（抗噪）。

调参：λL、λR 控制标记/排序样本的相对权重，网格搜索最小化验证集 MSE（可配合交叉验证）。

### 3.2 优化算法

- 约束问题 → 无约束：引入 hinge 损失 `L_hinge(t) = max(0, 1−t)`（式 3），问题凸但不可微；
- 用 **Huber 损失**替代 hinge（式 4）：

$$L_{huber}(t) = \max(0, 1-t)^2 - \max(0, -t)^2$$

  兼具 L1 的鲁棒性与 L2 的稳定性，且梯度、Hessian-向量积计算高效 → 问题变为**凸、无约束、可微**（式 5）；
- 取线性映射 f = bᵀx 后（式 6），用 **Newton 法**求解。

### 3.3 排序准则 d 的来源（医学依据）

- PD 运动障碍源于纹状体多巴胺耗竭；多巴胺能药物起效快、可维持数小时（尤其早期）；
- 因此"服药前比服药后更严重"是合理的排序假设；
- mPower 要求用户每天活动 3 次，至少一次服药前、一次服药后 → **天然产生排序样本对**；
- 对无排序样本的患者，模型预期退化为普通监督学习的表现。

## 4. 仿真实验（回答 4 个问题）

**数据生成**：x ~ MN(0, Rx)（Rx,i,j = a^|i−j|）；b ~ N(μb, σb²I)；y = bᵀx + ε；SNR = 5；15 个真实特征 + 15 个噪声特征。

**对比模型**：
- **RankSVM**：仅用排序样本（只能排序、不能直接预测 y，调参用 POC 准则）；
- **Ridge 回归**：仅用标记样本（与 RWSL 中标记样本部分结构相同）。

**评估指标**：MSE、预测相关性（Pearson）、特征选择精度 FS accuracy（区分真实/噪声特征）。

### 4.1 不同样本量下的表现（Q1）
- 20 个场景：从 10 标记 + 10 排序对 → 200 标记 + 1000 排序对；
- **RWSL 的 MSE 一致最低**（除最小样本场景 1 外均统计显著）；
- 与 ridge 的差距在**场景 2–6（标记样本有限时）最大** → 排序样本有效补偿了标签不足；
- RankSVM 存在性能上限（样本再多也不提升），且均值/方差波动大——它本质是排序模型而非预测模型。

### 4.2 排序样本节省标记样本（Q2）
- 场景 8：RWSL（80 标记 + 375 排序对）MSE = 0.937；ridge 需 **130 个标记样本**才达到统计等效；
- **结论：375 个排序对 ≈ 节省 50 个标记样本**。当标签昂贵、排序对廉价时，收益明确。

### 4.3 排序样本差异阈值的影响（Q3）
- 只纳入 |yi − yj| > Δy 的排序对，比较小（<1σ）、中（≈3σ）、大（>6σ）三档阈值；
- **中等阈值（约 3σ 噪声水平）最优**：阈值过低会纳入因噪声而错误排序的样本对；过高会丢弃大量有效排序对。→ 为实际应用提供了阈值选择指导。

### 4.4 对标签噪声的鲁棒性（Q4）
- 训练集加入 0%/20%/40%/60% 标签噪声（测试集保持干净）；
- 噪声越大，RWSL 相对 ridge 的优势越大 → 排序数据对标签噪声不敏感，提升了模型鲁棒性。

## 5. 真实数据应用（mPower）

### 5.1 数据
- **敲击活动**：患者每天 3 次（服药前/后/其他时间）用同手两指交替敲击屏幕两个固定点 20 秒；原始数据为触点 x-y 坐标时间序列；提取 **43 个特征**（敲击次数、平均/中位敲击间隔等）。
- **响应变量**：MDS-UPDRS 总分（0–64，0 健康、64 完全失能），按月收集，缺失严重 → 按文献支持的线性趋势**线性插值**为周频。

### 5.2 样本筛选
- 筛选条件：服药前 ≥30 次且服药后 ≥30 次敲击任务 → 57 人；
- 进一步要求药物响应显著（假设检验，Chaibub Neto et al., 2016）→ **16 名患者**；
- 3,711 条敲击记录 → 3 天窗口内配对 → **1,284 个有效排序对**；**168 个标记样本**。

### 5.3 结果（5 折 CV，Table 1）

| 模型 | 预测相关性 Mean (std) | MSE Mean (std) |
|---|---|---|
| RankSVM | 0.7335 (0.141) | 0.0384 (0.016) |
| Ridge 回归 | 0.6913 (0.158) | 0.0342 (0.016) |
| **RWSL** | **0.7579 (0.083)** | **0.0276 (0.013)** |

RWSL 同时取得最小 MSE、最高相关性和最小标准差（稳定性好）。

### 5.4 可解释性
- 系数绝对值最大的两个特征：**中位敲击间隔**与**平均敲击间隔**，占全部系数绝对值之和的 **37%**；
- 与医学文献一致：PD 患者因精细运动控制受损，指叩间隔更短。

## 6. 局限与未来方向

1. MDS-UPDRS 只是 PD 严重度的替代度量（latent construct），未来若有更完善的量表可重训 RWSL；
2. 自我采集中存在不依从/误操作缺失 → 需要更好的插补与预处理；
3. 目前仅用"服药"作为排序准则 → 可探索其他 PD 相关排序准则；
4. 临床落地挑战：研究数据质量高于普通人群、用户依从性、医生信任（需大量临床验证）、数据网络安全。

## 7. 关键贡献小结

1. **问题层面**：首次将"领域知识可排序的无标签样本"引入 PD 远程监护的严重度预测，填补 telemonitoring 分析中"从数据采集到严重度反馈"的空白；
2. **方法层面**：提出 RWSL——SVMRank 间隔最大化 + 监督二次损失的统一凸优化框架，Newton 法高效求解；
3. **实证层面**：仿真证明其在标签稀缺、标签噪声场景下的优势；mPower 真实数据上 MSE/相关性/稳定性全面优于 RankSVM 与 ridge 回归；
4. **量化收益**：375 排序对 ≈ 50 标记样本；排序对阈值建议 ≈3σ 噪声水平。
