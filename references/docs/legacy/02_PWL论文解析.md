## 2. 研究背景与问题定义

### 2.1 应用背景：制造过程质量预测

- 现代制造过程部署大量传感器采集过程参数 X，为预测/控制最终产品质量 Y 提供了机会；
- 但 X→Y 的关系往往不清楚，需要用历史**标记数据集**训练 ML 模型；
- **核心矛盾**：获取标签 Y 需要产线末端质量检测，通常昂贵，且破坏性检测（destructive testing）根本无法对所有产品实施 → **标记样本极其有限**；而工业过程本身噪声大，小样本难以训练鲁棒模型。

### 2.2 动机示例：点焊（spot welding）

- 破坏性检测（剥离试验、凿子试验）仍是点焊质量检测的主流，耗时、昂贵、无法用于连续生产；
- 目标质量：焊缝**温差 ΔT**；过程变量：压力 [kN]、电流 [kA]、焊接时间 [s]、质量 [g]；
- **物理模型**（基于热阻/热传导原理的数学公式）可估算 ΔT，成本远低于破坏性检测。

### 2.3 物理模型的三大局限（即 PWL 要解决的挑战）

1. **最终质量估计的不确定性**：物理模型只能接收少量过程变量作为输入 → 存在**模型差异（model discrepancy）** ε_disc；
2. **间接测量**：物理模型输出可能与最终质量高度相关，但并不直接测量同一个量（需要映射函数 ϕ）；
3. **校准问题**：物理模型含有不可观测的**校准参数 θ**（如材料属性、边界条件），传统做法是 ad-hoc 的两步法预校准（ Kennedy–O'Hagan 式），未与预测模型联合优化，可能次优/过拟合。

### 2.4 与现有研究的差距（Gaps）

| 研究路线 | 代表做法 | 不足 |
|---|---|---|
| 物理信息架构（physics-informed architecture） | 在 NN 结构中嵌入物理中间变量、能量守恒计算图 | 架构设计困难、高度应用特定 |
| 物理信息正则化（physics-informed regularization） | 损失函数中加入物理约束罚项（如 PDE 散度罚） | 输入变量不匹配、泛化受限、知识不完备、大网络非凸、损失项相互竞争 |
| 深度学习 + 物理 | 维度增广、物理先验、物理输出作输入、物理数据预训练 | 未直接解决数据稀缺；忽视校准问题 |
| 半监督 + 物理 | 用仿真数据做标签传播/预训练 | 重度依赖仿真数据质量；不处理不确定性与校准 |
| 弱监督（RWSL，医疗） | 领域知识排序弱标签 | 制造业无对应的"排序知识"；制造业由物理定律支配，需要**结构化、可量化**的弱标签来源 |

**PWL 的核心思想**：把物理模型的输出视为**弱标签（weak labels）**，与少量真实标记样本整合；同时**联合优化**数据驱动 ML 模型与物理模型的差异项/校准参数。

## 3. 方法论

### 3.1 符号与问题陈述

- **物理模型视角**：`y_i = ϕ[η(x_i^ph, θ)] + ε_i^disc + ε_i`
  - η(·,·)：物理模型确定性输出（数学公式或计算机仿真）；x^ph ∈ R^q1：物理模型输入变量；θ ∈ R^q3：校准参数（不可直接控制/测量，如材料属性、边界条件）；
  - ϕ：物理输出 → 真实质量的映射；ε^disc：模型差异项；ε：随机误差。
- **数据驱动视角**：`y_i = f(x_i^ph, x_i^pr) + ε_i`
  - x^pr ∈ R^q2：物理模型**未包含**的可测过程变量（如点焊中的压力）；
  - 局限：标签稀缺 → 训练不鲁棒；纯数据驱动、不用物理知识。
- **联合真值视角（式 3）**：`y_i = u(x_i^ph, x_i^pr, θ) + ε_i`
  - 质量 y 同时受三类变量影响；忽略式 3 的建模都是次优的。**PWL 的目标就是在尊重式 3 的前提下整合两类模型。**

### 3.2 联合模型形式化（式 4）

$$y_i = H(x_i^{ph}, \theta)\,g + B(x_i^{pr}, x_i^{ph})\,d + \varepsilon_i$$

- H(·,·)：基于 x^ph 与 θ 的**基函数**（生成模式 patterns），g ∈ R^p：对应系数；
- B(·,·)：基于 x^pr 与 x^ph 的基函数，d ∈ R^b：对应系数。

该结构的三大优势：

1. **知识蒸馏（knowledge distillation）**：第一项与物理模型共享输入 (x^ph, θ)，使 H·g 能从物理模型 η 产生的海量弱标签样本中学习（教师→学生），缓解标签短缺；
2. **差异补偿**：第二项建立在 x^ph + x^pr 之上，用数据驱动项弥补单独使用物理模型的差异；
3. **高度灵活**：基函数可按问题定制，适用于多种制造场景。

注意：**校准参数 θ 被纳入模型形式化**，可与其它模型参数一起优化，而非预先校准。

### 3.3 优化问题（式 5）

$$\min_{g,\theta,d}\; \underbrace{\sum_{i=1}^{n}\|y_i - H(x_i^{ph},\theta)g - B(x_i^{pr},x_i^{ph})d\|_F^2}_{\text{① 标记样本预测误差}} + \underbrace{\lambda_1\sum_{j=1}^{N}\|H(x_j^{ph},\theta)g - \phi[\eta(x_j^{ph},\theta)]\|_F^2}_{\text{② 向物理模型弱标签蒸馏}} + \underbrace{\lambda_2\|g\|_1}_{\text{③ L1}} + \underbrace{\lambda_3\sum_{q=1}^{q_1+q_3}\|g_q\|_2}_{\text{④ 组Lasso}}$$
$$\text{s.t. } \omega_l \le \theta \le \omega_u$$

- n = 真实标记样本数；N = 物理模型生成样本数，**N ≫ n**；
- ② 的双重作用：(a) 控制 H·g 向物理模型学习的强度——物理模型越不准，λ1 应越小；(b) 通过 ϕ 处理"质量 y 与物理输出 η 测的不是同一个量"的失配；
- ③+④ = **稀疏组 Lasso（sparse group lasso）**：同时做变量选择与组选择；因为 H 生成的模式中有些描述同一物理现象应同进同出，且模式间不独立，该罚项有助于**可辨识性（identifiability）**；
- 问题**非凸** → 用 BCD 分解为三个凸子问题。

### 3.4 算法（Algorithm 1：BCD）

**PWL 算法流程**（块坐标下降）：

1. **g 更新** → ADMM 一致性算法（式 6→7，M=4 个凸函数之和；近端算子见 Proposition 1，推导见补充材料 A 节）；
2. **d 更新** → 最小二乘**闭式解**；
3. **θ 更新** → ADMM（式 8，M=3；盒约束近端算子见 Proposition 2，推导见补充材料 B 节）；

直到目标值变化 < ε0。

**初始化策略**（两个直观考虑）：
- d 用小值初始化 → 让 g 在第一轮更新中优先向物理模型学习；
- θ 用两步法（式 12）校准结果初始化 → 让物理模型一开始就处于最佳可用状态。

### 3.5 理论性质：可辨识性与唯一性（Proposition 3）

- H₁g 的估计可视为**字典学习**问题（学基矩阵 H₁ + 稀疏系数 g），不保证唯一 → 需可辨识性条件；
- **H 已知**时（压缩感知理论）：g 为 k-稀疏（k ≪ m），H 满足 **spark 条件**（Hg₁ = Hg₂ ⇒ g₁ = g₂），且样本数满足 `n ≥ C·k·log(m/k)`（C 与 m,n,k 无关）→ 可唯一恢复 g；
- **H 未知**时：存在置换/对角缩放歧义 Aa = (AD⁻¹Pᵀ)(PDa)；若能从系统子采样 N 个相似样本，则当 `N = (k+1)/β · C(m,k)` 时，以概率 1−β 保证基矩阵唯一（稀疏矩阵分解唯一性）。

## 4. 仿真实验

### 4.1 设置

- 数据生成（基于 Bastos & O'Hagan 玩具算例改造）：
  - (x^pr, x^ph) ~ MN(0, Σx)；θ ~ U(0,1]；y = η_true(x^ph, θ) + h(x^pr) + ε；SNR = 5；
  - q1=3, q2=2, q3=2；
  - η_true（式 9）= (1−exp(−1/(2x₃))) × (10θ₁x₁³+19x₁+60)/(9θ₂x₂³+4x₂+20)；δ(x^ph)（式 10）= (10x₁²+4x₂²+2x₃³)/(50x₁x₂+10)，模拟物理模型差异；h(x^pr)（式 11）= (4x₄²+8x₅²)/(5x₄x₅)，为未入物理模型的变量贡献（三式已经 PDF 版面坐标精确确认，见 [07_PWL复现指南 §9](../07_PWL复现指南.md)）；
  - 观测到的物理模型：η = η_true + δ + ε_η（即"不那么准确"的版本）。
- **对比模型**：Ridge（线性代表）、SVR（核方法，多项式核）、DT（树）、RF/GBDT（集成）、GP（高斯过程，平方指数核）、**Physics**（两步法校准 + GP 差异建模，Kennedy–O'Hagan 路线）。
- 指标：MSE、RMSE、MAE（多种子重复取均值±标准差）。

### 4.2 结果

**(A) 不同样本量（12 场景：10→120 标记样本；每场景 100 个物理模型样本）**
- PWL 在所有场景 RMSE 一致最优（单侧检验显著）；
- **标记样本越少，PWL 优势越大**；物理模型单独使用存在性能上限（结构不灵活）；
- 箱线图显示 PWL 的均值与离散度下降更快、更稳。

**(B) 物理模型精度的影响**（相关性 0.85 / 0.7 / 0.5 三档；40 标记 + 100 物理样本）
- 物理模型越准，PWL 越好（PWL-H 最优）；
- **关键结论**：即使物理模型精度不足（PWL-L，相关 0.5），PWL 表现仍与最优对比模型**统计上无差异**——因为 λ1 可调低对物理模型的依赖 → PWL 具有"进可攻、退可守"的稳健性。

**(C) 标签节省**：场景 3 中 PWL（30 标记 + 100 物理样本）MSE = 3.745；最优对比模型需 **100 个标记样本**才达到统计等效 → **标记样本需增加 233.3%**，PWL 在标签昂贵场景收益巨大。

## 5. 案例研究

### 5.1 案例 A：点焊温差预测（自研实验）

- 设备：75-kVA X 型焊枪，红外相机（TACHYON 1024 µCAMERA）监测熔核与温度；CuCrZr 球头电极（每 5 焊点更换）；St1203 低碳钢板（20×40 mm，厚 1–3 mm）；
- 4 个可控变量：压力 x1、电流 x2、时间 x3、质量 x4；35 组 Latin Hypercube 实验；
- **物理模型（式 13）**：`ΔT = I²·ρ·L·t / (A·m·Cp)`，含校准参数 ρ（电阻率）、Cp（热导率）等 → x^ph = {x2,x3,x4}，x^pr = {x1}；
- 两步法校准后：与过程样本相关性 0.884，但 RMSE 高达 72.8 → **"高相关、低精度"，正是 PWL 的理想候选**；
- 结果（Table III，5 折 CV × 5 随机次）：PWL 在 RMSE/MSE/MAE 全面最优且标准差最小；
- 与半监督模型对比（Table IV，仅 15 个标记，其余作无标签；对比 CoReg (Zhou & Li, 2005)、ICT (Verma et al., 2022)、Π Model (Laine & Aila, 2016)、Mean Teacher (Tarvainen & Valpola, 2017)）：PWL 在均值与稳定性上均最优。

### 5.2 案例 B：熔核直径预测（文献数据，Bayarri et al. 2007）

- 3 个过程变量：载荷 x1、电流 x2、板厚 x3；目标：熔核直径 y；
- 物理模型：热-电-力耦合 PDE，**ANSYS 仿真**，含 1 个校准参数；先用 **Kriging**（普通克里金 + 高斯相关函数）拟合 35 组仿真以近似仿真器；
- 过程样本：12 个设置 × 10 重复 = **120 个**；由重复样本估计噪声方差 ≈ 0.2；
- 两种数据可用性场景：10 标记 vs 100 标记（Table V/VI）：
  - 100 标记时 PWL 的 MSE = **0.206**，逼近噪声方差 0.2（理论上能达到的最好水平）；
  - 10 标记时 PWL 全面优于基准；PWL 随标签增多的提升幅度也大于半监督模型（既能用无标签数据、又能随标签扩展）。

## 6. 结论与未来方向

**方法论优势**：预测性能显著提升 + ADMM 高效优化；证明弱监督是制造质量预测中替代"昂贵大标签数据集"的可行范式。

**未来方向**：
1. 扩展到更复杂/高维输出；
2. 处理物理模型的内生不确定性（区间输出 → 加权损失、软约束、概率输出）；
3. 迁移到其它标签稀缺领域：无损检测、预测性维护；
4. 与深度学习、强化学习、众包/半监督等弱监督方法结合；
5. 引入领域专家启发式、材料科学等更深层领域知识。

## 7. 关键贡献小结

1. **概念创新**：首次将"物理模型输出"定义为弱监督学习中的**弱标签**，打通 physics-informed ML 与 WSL 两个领域；
2. **框架创新**：基函数联合模型 y = Hg + Bd + ε，知识蒸馏 + 差异补偿 + **校准参数内生化联合优化**；
3. **算法与理论**：BCD + ADMM 一致性算法（全部子问题凸），并给出压缩感知/字典学习意义下的可辨识性条件；
4. **实证充分**：仿真（样本量/物理精度/标签节省三视角）+ 两个点焊真实案例（温差、熔核直径），对监督、半监督、物理模型基线全面胜出；
5. **量化收益**：100 物理样本 ≈ 节省约 70% 标记样本（30→100，+233.3%）。
