# 06 方法体系：RWSL → PWL → M2WeST 的演进与对比

> 本文是文献框架的**综合分析篇**，将三篇核心工作（[01_RWSL](01_RWSL论文解析.md)、[02_PWL](02_PWL论文解析.md)、[05_M2WeST](05_M2WeST方法解析.md)）置于同一坐标系下比较，梳理其内在演进逻辑与共性技术脉络。

---

## 1. 一句话定位

| 方法 | 一句话 |
|---|---|
| **RWSL**（2022） | 用**领域知识产生的排序对**作弱标签，与少量标记样本联合训练回归模型（单患者、医疗） |
| **PWL**（2024/25） | 用**物理模型输出**作弱标签，联合优化 ML 模型与物理模型的差异/校准参数（单过程、制造） |
| **M2WeST**（2024） | 用**排序弱标签 + 多源患者数据**，通过特征增广迁移学习实现个性化预测（多患者、医疗） |

## 2. 核心问题对比

| 维度 | RWSL | PWL | M2WeST |
|---|---|---|---|
| 应用域 | PD 远程监护 | 制造过程质量预测 | PD 远程监护 |
| 预测目标 Y | MDS-UPDRS（0–64） | 产品质量（温差 ΔT / 熔核直径） | MDS-UPDRS（0–64） |
| 特征 X | 敲击活动 43 维 | 过程变量（x^ph + x^pr） | 敲击 43 维 / 语音 339 维 |
| 标签瓶颈 | 临床评估每 4–6 个月一次 | 末端质检昂贵、破坏性检测 | 同 RWSL + 患者异质性 |
| **弱标签来源** | 领域知识排序（服药前 ≻ 服药后） | 物理模型 η(x^ph, θ) 的输出 | 排序对（目标 + 各源患者） |
| 弱标签类型 | 成对序约束 y_i ≥ y_j | 连续数值（含偏差、需映射 ϕ） | 成对序约束（多源） |
| WSL 类别 | incomplete supervision | incomplete supervision（弱标签来自物理模型） | incomplete supervision |
| 数据主体 | 单患者 | 单制造过程 | **多患者（多源）+ 目标患者** |
| 额外挑战 | 标签噪声、缺失 | 模型差异 ε_disc、校准 θ、间接测量 | 患者异质性、负迁移 |

## 3. 模型结构对比

| | RWSL | PWL | M2WeST |
|---|---|---|---|
| 预测函数 | f_b(x) = bᵀx（线性） | y = H(x^ph,θ)g + B(x^pr,x^ph)d + ε（基函数分解） | f_β(h(x))，h(x)=[x, g_θ1..S(x)]（增广线性） |
| 监督项 | 标记样本二次损失 | 标记样本拟合 ‖Y−H₁g−B₁d‖²_F | 目标 + 各源监督损失 |
| 弱监督项 | 排序 hinge：max(0, 1−bᵀ(x_i−x_j)) | 蒸馏项 λ₁‖H₂g−ϕ(η)‖²_F | 目标 + 各源排序 hinge |
| 正则 | ½‖b‖²（间隔最大化） | 稀疏组 Lasso λ₂‖g‖₁+λ₃Σ‖g_q‖₂；θ 盒约束 | 弹性网 λ₁\|β\|₁+λ₂\|β\|²；源 L2 |
| 可调权重 | λ_L、λ_R | λ₁（物理强调）、λ₂、λ₃ | λ_w^t, λ_1^t, λ_2^t, λ_l^s, λ_w^s, λ_2^s |
| 特殊机制 | 排序阈值 Δy（≈3σ 最优） | **校准参数 θ 内生联合优化**、映射 ϕ | **特征增广 h(x)**、**源预选 Algorithm 5** |
| 优化 | Newton 法（Huber 化后凸且光滑） | BCD（g/d/θ）+ ADMM 一致性算法 | BCD（β/θ_s）+ ADMM 一致性算法 |
| 理论 | —（凸性、仿真实证） | 可辨识性：spark 条件 + n≥Ck·log(m/k)；N=(k+1)/β·C(m,k) | 泛化界 Proposition 6（Robinson et al. 2020 路线） |
| 调参 | 网格搜索（验证 MSE） | 验证集 MSE | Optuna（TPE） |

## 4. 演进逻辑（三部曲叙事）

```
RWSL (2022, 医疗)                        PWL (2024, 制造)                M2WeST (2024, 医疗)
─────────────────                        ──────────────────              ─────────────────────
标签稀缺?                                 标签稀缺?                       标签稀缺 + 患者异质?
→ 领域知识还能提供什么?                    → 领域知识以何形式存在?          → 其他患者能否帮忙?
→ 排序对 (y_i ≥ y_j)                      → 物理模型 (第一性原理)          → 可以, 但要防负迁移
→ SVMRank 间隔 + 监督损失                  → 知识蒸馏 + 差异补偿            → 弱监督 × 多源迁移
→ 单患者                                  → + 校准参数联合优化             → 特征增广 + 源预选
        │                                        │                              │
        └──────────── 共同母题: "弱监督学习 (WSL) 利用弱标签弥补强标签不足" ──────┘
```

**演进的三条线索**：

1. **弱标签来源的泛化**：领域知识排序（RWSL）→ 物理模型输出（PWL）→ 排序 × 多源（M2WeST）。本质是"凡是比精确标签便宜、又携带 Y 信息的信号，都可作弱标签"；
2. **数据结构的扩展**：单患者/单过程（RWSL、PWL）→ 多源异质主体（M2WeST）；
3. **领域间的迁移**：医疗（RWSL）→ 制造（PWL）→ 回到医疗并升级为多源（M2WeST）。PWL 论文明确指出：制造业没有医疗中那种"知识驱动的排序"，但制造业由物理定律支配 → 物理模型天然提供结构化、可量化的弱标签。这是两个领域方法互鉴的关键论点。

## 5. 共性技术脉络

1. **统一优化范式**：所有方法都把"强标签拟合 + 弱标签约束 + 稀疏/间隔正则"写成一个（块）凸优化问题；非凸时用 BCD 分解为凸子问题；
2. **损失函数工程**：hinge → Huber（RWSL、M2WeST）保证凸且可微；
3. **ADMM 一致性算法**：PWL 与 M2WeST 共用同一求解骨架（Proposition 1–5 的近端算子全部闭式），M=3/4 个函数并行更新；
4. **间隔最大化 / 排序约束**：RWSL 的 SVMRank 思想延续到 M2WeST 的目标/源排序损失；
5. **"弱标签可信度"自适应**：RWSL 的 λ_R 与排序阈值 Δy、PWL 的 λ₁（物理模型不准就调小）、M2WeST 的 λ_w 与源预选——都体现"按弱标签质量调节依赖度"的设计哲学；
6. **实证范式一致**：仿真（系统扫描样本量/噪声/弱标签质量）+ 真实案例 + 统计显著性检验 + "节省多少标记样本"的量化分析。

## 6. 实证亮点速查

| 方法 | 仿真关键结论 | 真实数据 | 量化收益 |
|---|---|---|---|
| RWSL | 标签越少优势越大；抗标签噪声 | mPower 敲击（16 患者，168 标记，1284 排序对）：MSE 0.0276，Corr 0.758 | 375 排序对 ≈ 50 标记样本 |
| PWL | 物理模型相关 0.5 时仍不输最优基线 | 点焊温差（35 样本）+ 熔核直径（120 样本，MSE 0.206 ≈ 噪声方差 0.2） | 物理样本使标签需求 +233.3% 等效（30→100） |
| M2WeST | 源异质、源标签少、弱标签噪声下均最稳 | mPower 敲击 MSE 1.229 / 语音 MSE 1.708，优于 6 个基线 | 敲击 Corr 0.641 vs RWSL 0.544 / SL 0.477 |

## 7. 局限与开放问题（跨三篇共性 + 各自特有）

**共性**：
1. 弱标签质量依赖领域知识/物理模型的可靠性——缺少弱标签可信度的显式不确定性建模；
2. 理论保证仍不完整（RWSL 无泛化理论；M2WeST 仅单源有界；PWL 可辨识性条件较强）；
3. 真实世界部署（数据缺失、不依从、临床信任、工业实时性）未解决。

**各自特有**：
- RWSL：仅"服药"一种排序准则；MDS-UPDRS 是替代指标；
- PWL：单输出；物理模型内生不确定性（区间/概率输出）未处理；
- M2WeST：无时序建模；多源情形泛化界未形式化。

## 8. 未来研究地图（整合学位论文第 5 章与三篇论文展望）

1. **弱监督机制扩展**：更多排序准则（医疗）、专家启发式/材料知识（制造）、患者特异性弱标签；
2. **模态与时间维度**：多模态（语音+视频+传感）、时序动态建模；
3. **不确定性量化**：概率输出、加权损失、软约束、物理模型区间输出；
4. **规模化与分布式**：联邦学习跨产线/跨医院校准；实时自适应预测；
5. **理论化**：三模型在不同噪声/缺失/弱标签质量下的泛化、鲁棒、收敛保证；
6. **应用迁移**：阿尔茨海默、糖尿病（医疗）；预测性维护、无损检测（制造）；
7. **与深度方法结合**：深度网络、强化学习、众包弱监督。
