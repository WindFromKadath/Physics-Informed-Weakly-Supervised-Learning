## 2. A 节：g 更新（Proposition 1）

**问题**：在 BCD 的 g 更新步，需求解四个凸函数之和：
- f₁(g) = ‖Y − H₁g − B₁d‖²_F（标记样本拟合项）
- f₂(g) = λ₁‖H₂g − η̃‖²_F（物理模型蒸馏项，η̃ = ϕ[η(x^ph, θ)] 的堆叠向量）
- f₃(g) = λ₂‖g‖₁（L1 稀疏）
- f₄(g) = λ₃ Σ_q ‖g_q‖₂（组 Lasso）

**四个近端算子**（z、a 与 g 同维，Δ 为步长）：

1. **prox_{Δf₁}[a] = (I + ΔH₁ᵀH₁)⁻¹ (a + ΔH₁ᵀ(Y − B₁d))**
   - 推导：把 f₁ 写成最小二乘标准形 ‖(Y−B₁d) − H₁g‖²_F，套用文献[46]中 q(x)=‖c−Px‖² 的近端公式 prox = (I+ΔPᵀP)⁻¹(x+ΔPᵀc)，取 P=H₁、c=Y−B₁d。
2. **prox_{Δf₂}[a] = (I + λ₁ΔH₂ᵀH₂)⁻¹ (a + λ₁ΔH₂ᵀη̃)**
   - 与 f₁ 同构，取 P=H₂、c=η̃。
3. **prox_{Δf₃}[a] = S_{λ₂Δ}(a)** —— L1 的**软阈值（soft-thresholding）**：
   - a − λ₂Δ（a > λ₂Δ）；0（|a| ≤ λ₂Δ）；a + λ₂Δ（a < −λ₂Δ）。
4. **prox_{Δf₄}[a] = [1 − λ₃Δ/‖a‖₂]₊ a** —— L2 范数的**组收缩（block soft-thresholding）**，由近端算子的可分离性（separable property）得到。

**意义**：f₁、f₂ 有闭式矩阵解，f₃、f₄ 有逐元素/逐组闭式解 → ADMM 一致性算法每轮迭代全部**显式更新、可并行**，无需内部迭代求解器。

## 3. B 节：θ 更新（Proposition 2）

**问题**：θ 更新步最小化（带盒约束 ω_L ≤ θ ≤ ω_U）：
- f₁ = ‖Y − H₁g − B₁d‖²_F（此时优化变量为 θ，H₁ 含 θ 的线性参数化使得该式关于 θ 为二次型）
- f₂ = λ₁‖H₂g − η̃‖²_F
- f₃ = Σ_k I{ω_Lk ≤ θ_k ≤ ω_Uk}（盒约束指示函数）

**三个近端算子**：

1. **prox_{Δf₁}[a] = (I + Δggᵀ)⁻¹ (a + Δg(Y − B₁d)ᵀ)**
   - 推导：f₁(θ) 重写为关于 θ 的最小二乘，取 P = gᵀ、c = (Y−B₁d)ᵀ、x = H₁ᵀ。
2. **prox_{Δf₂}[a] = (I + λ₁Δggᵀ)⁻¹ (a + λ₁Δgη̃ᵀ)**，同构。
3. **prox_{Δf₃}[a_k] = max(ω_Lk, min(a_k, ω_Uk))** —— 逐分量**截断/投影**到盒约束内（可分离性 + 盒约束近端公式，[46]）。

**意义**：θ 的更新同样是闭式的；盒约束保证校准参数停留在物理合理区间（如电阻率、热导率的已知上下界）。

## 4. C 节：可辨识性要求（Proposition 3）

**问题**：形如 H₁g 的项涉及"学基矩阵 + 学稀疏系数"，本质是**字典学习/稀疏矩阵分解**，解一般不唯一（如置换与对角缩放歧义：`Aa = (AD⁻¹Pᵀ)(PDa)`，P 为置换矩阵、D 为可逆对角矩阵）。需要统计条件保证可辨识。

### 4.1 基矩阵已知（压缩感知情形）

- 设 g 为 **k-稀疏**（至多 k ≪ m 个非零元）；
- **Spark 条件**：H g₁ = H g₂（g₁、g₂ 均 k-稀疏）⇒ g₁ = g₂；
- 信号模型：Ỹ = Hg，其中 Ỹ = Y − B₁d；
- **样本下界**：`n ≥ C·k·log(m/k)`（C 与 m、n、k 无关）→ 保证从信号 Ỹ 唯一恢复稀疏向量 g（压缩感知经典结果，[1][17]）。

### 4.2 基矩阵未知（字典学习情形）

- 在上述条件成立的前提下，若能从系统**子采样 N 个相似样本** Ỹ = {Ỹ₁, …, Ỹ_N}（各子样本可对应基矩阵的不同活跃模式）；
- 则当 **`N = (k+1)/β · C(m, k)`**（C(m,k) 为二项系数）时，以概率 **1−β** 保证基矩阵 H 唯一（稀疏矩阵分解唯一性，[28]）。

### 4.3 证明思路

- 取 λ₁ ≈ 0 的退化情形（λ₁ 仅控制物理模型强调程度，不失一般性），问题退化为 min ‖Ỹ − H₁g‖²_F + λ₂‖g‖₁ + λ₃Σ‖g_q‖₂，即带稀疏正则的矩阵分解；
- 先引用压缩感知理论（spark 条件 + 样本下界）讨论 **g 恢复精度**（对应 Algorithm 1 的 g 更新）；
- 再讨论 **A 未知时的置换/缩放歧义**，通过子样本多样性 + 字典学习唯一性下界排除歧义。

## 5. 对正文的意义与阅读建议

1. **算法可实施性**：A、B 两节证明 PWL 的 ADMM 每步都有闭式近端算子 → 算法高效、稳定、可并行，这是论文"efficient optimization via ADMM"宣称的技术基础；
2. **统计合法性**：C 节给出"基函数模式 + 稀疏系数"表示何时可被唯一识别，回应了基函数模型潜在的**可辨识性**质疑，也是正文采用稀疏组 Lasso 罚的理论动机之一；
3. **阅读顺序建议**：先读 [02_PWL论文解析](02_PWL论文解析.md) 的 §3.4–3.5 建立整体图景，再用本文件对照公式细节；
4. 关键外部文献：[46] ADMM 一致性算法与近端算子表（Boyd 等）；[1] Baraniuk 等 RIP 简证；[17] Donoho 压缩感知；[28] 字典学习唯一性。
