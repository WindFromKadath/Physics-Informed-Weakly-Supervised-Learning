# 08 PWL 基函数设计逻辑：从问题结构到基函数库

> **主题**：PWL 联合模型 `y = H(x^ph,θ)g + B(x^pr,x^ph)d + ε`（式 4）中，基函数 H 与 B **为什么这样设计、依据什么设计、以及如何实例化**。
>
> **定位**：本文是关于"基函数设计逻辑"的专题文档，综合三方面的分析——
> ① 论文文本中的设计意图（[02_PWL论文解析](legacy/02_PWL论文解析.md) §3）；
> ② 算法层面的隐含约束（[03_PWL补充材料解析](legacy/03_PWL补充材料解析.md)）；
> ③ 仿真代数公式确认后的实例化方案（[07_PWL复现指南](07_PWL复现指南.md) §4、§8、§9）。

---

## 1. 为什么基函数是 PWL 的核心设计问题

PWL 论文将基函数留给使用者（"highly flexible framework"），但基函数的选择实际上决定了三件事：

1. **蒸馏是否有效**：H 的函数族必须能（近似）覆盖物理模型 η 的输入-输出关系，否则蒸馏项 λ₁‖H₂g−ϕ(η)‖²_F 拟合不足，弱标签信息白白浪费；
2. **模型是否可解**：论文的 BCD-ADMM 算法要求 θ 更新是最小二乘结构 → 只有 H 对 θ **仿射**时闭式近端算子才成立；
3. **参数是否可辨识**：H·g 与 B·d 若张成相近空间，g、d、θ 将互相混淆（不可辨识），正则与结构设计必须避免这一点。

因此，基函数不是"任意细节"，而是连接**物理知识、统计效率与优化可行性**的枢纽。

## 2. 设计逻辑的总链条

```
【问题层】真实结构 y = u(x^ph, x^pr, θ) + ε            （式 3：变量三分）
     │
     ▼
【结构层】y = H(x^ph,θ)g + B(x^pr,x^ph)d + ε           （式 4：两组基函数对位映射）
     │
     ├─ H ← 与物理模型 η(x^ph,θ) 输入对齐 ──→ 目的①：知识蒸馏
     ├─ B ← 覆盖物理模型遗漏的 x^pr ────────→ 目的②：差异补偿
     └─ θ 显式入基 ─────────────────────────→ 目的③：校准内生
     │
     ▼
【约束层】算法与统计对基函数的硬性约束
     ├─ 约束 A：H 对 θ 仿射（否则 θ 更新无闭式 prox）
     ├─ 约束 B：按输入变量分 q1+q3 组（稀疏组 Lasso 的组结构）
     └─ 约束 C：H 与 B 的列空间尽量不相交（可辨识性）
     │
     ▼
【实例层】由仿真公式（式 9–11）推导具体基函数库
     ├─ H 库：p = 25，5 组（G_x1, G_x2, G_x3, G_θ1, G_θ2）
     └─ B 库：b = 12（x^pr 比值/多项式 + x^ph 残差特征）
```

## 3. 设计依据：基函数建立在什么内容之上

### 依据 1：联合真值的变量三分结构（式 3）

论文论证真实过程为 `y = u(x^ph, x^pr, θ) + ε`，并指出 *"Models that are developed without taking Eq. 3 into consideration will lead to suboptimal solutions"*。基函数的划分正是对该变量结构的**逐项映射**：

| 基函数 | 覆盖变量 | 在真值中的角色 |
|---|---|---|
| H(x^ph, θ) | 物理输入 + 校准参数 | 与物理模型 η(x^ph, θ) **完全相同**的输入 |
| B(x^pr, x^ph) | 全部可测过程变量 | 物理模型因"输入不足"而遗漏的部分 |

### 依据 2：与物理模型输入对齐（知识蒸馏的前提）

原文 §III-B：*"the model is structured in a way that it allows the first term to have the same input as the physics-based model to allow knowledge distillation"*。

H·g 与 η(x^ph, θ) 共享输入是**刻意构造的师生关系**：只有输入一致，蒸馏项才能在任意 x^ph 处让 H·g 直接拟合 η 的输出（教师 η → 学生 H·g，Hinton et al. 2015 [29]）。

### 依据 3：稀疏模式表示 / 字典学习

原文 §III-B：*"The basis matrix formed by H and B are used to represent patterns in the original feature matrix"*；§III-D3：*"This problem can be cast as a dictionary learning problem"*。

未知响应面 u(·) 被表示为若干"模式（patterns）"的稀疏线性组合——基函数即模式库，系数 g/d 是模式的选择与权重。这直接引向压缩感知/字典学习的可辨识性理论（命题 3：spark 条件、样本下界）。

## 4. 设计目的：每一项要解决什么问题

| # | 目的 | 机制 | 对应的论文挑战 |
|---|---|---|---|
| ① | **知识蒸馏**，缓解标签稀缺 | H 与 η 共享输入 → 可在 N≫n 的物理弱标签样本上训练 | 标记样本昂贵/稀缺 |
| ② | **差异补偿**，弥补物理模型不完备 | B 建立在 x^pr+x^ph 上，捕捉 η 无法纳入的变量效应 | 挑战 1：模型差异 ε_disc |
| ③ | **校准参数内生优化** | θ 显式写入 H → 与 g、d 联合优化 | 挑战 3：ad-hoc 两步校准 |
| ④ | **模式选择 + 可辨识性** | 稀疏组 Lasso：L1 选个体、组罚让"同一现象的模式同进同出"；缓解模式间不独立 | 统计合法性（命题 3） |
| ⑤ | **灵活性 + 可解性** | 基类型可换 → 框架通用；y 对 g、d 线性、对 θ 仿射 → BCD 各子问题凸、prox 闭式 | 算法可实施性 |

## 5. 算法层面的三条硬性约束（从证明反推）

### 约束 A：H 必须对 θ 仿射（线性）

θ 更新的近端算子（命题 2）为 `prox_{Δf₁}[a] = (I + Δggᵀ)⁻¹(a + Δg(Y−B₁d)ᵀ)`——这是**最小二乘结构**，仅当 `H₁(θ)g = c₀ + G·θ`（H 对 θ 仿射）时成立。

> **设计规则**：θ 只能以**一次形式**进入基函数（θ、θ×x 交互允许；θ²、θ 的有理/指数形式禁止——否则会破坏论文算法，需改用梯度类方法）。

⚠️ 论文记号瑕疵提醒：命题 2 中"I 为 p 阶单位阵"应为 **q₃ 阶**，复现时需按 `c₀ + Gθ` 自行整理维度。

### 约束 B：分组数为 q1+q3

优化目标中的组罚为 `λ₃Σ_{q=1}^{q1+q3}‖g_q‖₂`（式 5），共 **q1+q3 组** → 分组按 **H 的输入变量**（仿真中 x₁,x₂,x₃,θ₁,θ₂ 共 5 组）划分，即"同一变量派生的模式同进同出"（原文：*"Some of those patterns are related to the same phenomena, and hence we desire their effects to be chosen or unchosen together"*）。

### 约束 C：H 与 B 的列空间尽量不相交（可辨识性）

命题 3 只处理 H 内部（基矩阵 H 与稀疏系数 g 的唯一性）；**H 与 B 之间**的混淆需由设计避免。借鉴 Plumlee (2017, JASA) 的正交化原则：B 中与 H 重叠的特征应剔除、降权，或对 B 做关于 H 列空间的残差化。

## 6. 实例化：由仿真公式（式 9–11）推导基函数库

### 6.1 确认后的仿真公式（PDF 版面分析，证据见 [07 §9.1](07_PWL复现指南.md)）

$$\eta_{true}(x^{ph},\theta) = \Big(1-\exp\big(-\tfrac{1}{2x_3}\big)\Big)\times\frac{10\theta_1x_1^3 + 19x_1 + 60}{9\theta_2x_2^3 + 4x_2 + 20} \tag{9}$$
$$\delta(x^{ph}) = \frac{10x_1^2 + 4x_2^2 + 2x_3^3}{50x_1x_2 + 10} \qquad h(x^{pr}) = \frac{4x_4^2 + 8x_5^2}{5x_4x_5} \tag{10,11}$$

数据流：`y = η_true + h + ε`（SNR=5）；可观测物理模型 `η_obs = η_true + δ + ε_η`；x^ph=(x₁,x₂,x₃)、x^pr=(x₄,x₅)、θ=(θ₁,θ₂)~U(0,1]²。

### 6.2 公式结构 → 设计约束（代数层面的四条规则）

| # | 公式事实 | 设计规则 |
|---|---|---|
| R1 | 饱和因子 **S(x₃) = 1−exp(−1/(2x₃))** 强非线性 | H 必须含 S(x₃) 类特征，否则蒸馏欠拟合 |
| R2 | **θ₂ 在真值分母中 → θ 非线性** | 与约束 A 冲突 → H 用 θ 一次特征做**局部线性近似**，残差交 B·d 与标记数据吸收（这正是 PWL"物理模型不准也能用"的机制） |
| R3 | δ 只含 x^ph，被 η_obs 带入弱标签 | 蒸馏把 δ 一起教给 H·g（弱标签**有偏**）→ 纠偏靠 B·d（x^pr 信息）+ 标记样本 |
| R4 | h 是零阶齐次比 = (4/5)(x₄/x₅)+(8/5)(x₅/x₄) | B 含**比值特征**可精确表示 h；纯多项式只能近似 |

### 6.3 H(x^ph, θ) 基函数库（蒸馏项，p=25，5 组）

| 组 | 基特征 | 对应真值结构 |
|---|---|---|
| G_x1（4） | 1, x₁, x₁², x₁³ | 式 (9) 分子的 x₁ 通道 |
| G_x2（3） | x₂, x₂², x₂³ | 式 (9) 分母的 x₂ 通道 |
| G_x3（8） | x₃, x₃², x₃³, S(x₃), S(x₃)x₁, S(x₃)x₂, S(x₃)x₁³, S(x₃)x₂³ | 饱和因子及其交互 |
| G_θ1（5） | θ₁, θ₁x₁, θ₁x₁³, θ₁S(x₃), θ₁x₁³S(x₃) | θ₁ 通道（θ 一次，仿射） |
| G_θ2（5） | θ₂, θ₂x₂, θ₂x₂³, θ₂S(x₃), θ₂x₂³S(x₃) | θ₂ 通道（θ 一次，仿射） |

- 记 S(x₃) = 1 − exp(−1/(2x₃))；
- **可选增强**（逼近式 (9) 分母的有理结构，不破坏线性）：固定系数有理特征 1/(20+4x₂)、x₁/(20+4x₂)、S(x₃)/(20+4x₂)；
- H₁（n 个标记样本）与 H₂（N 个物理样本）共用同一库，仅在各自 x^ph 与当前 θ 处求值。

### 6.4 B(x^pr, x^ph) 基函数库（补偿项，b=12）

| 部分 | 基特征 | 目标 |
|---|---|---|
| x^pr 通道（8） | 1, x₄, x₅, x₄², x₅², x₄x₅, **x₄/x₅, x₅/x₄** | 精确/近似表示 h（式 11，规则 R4） |
| x^ph 通道（4） | x₁², x₂², x₃³, x₁x₂ | 吸收 δ（式 10）经蒸馏残留的差异（规则 R3） |

- **约束 C 的处理**：x^ph 通道与 H 库重叠（x₁²、x₂²、x₃³）→ 复现两版本对照：(a) 直接使用（靠 λ₂/λ₃ 调节）；(b) 对 B 的 x^ph 部分做关于 H 列空间的正交化。

### 6.5 配套设计

| 项 | 配置 | 依据 |
|---|---|---|
| ϕ | 恒等映射 | 仿真中 η_obs 与 y 同量纲 |
| θ 盒约束 | ω_l=(0,0)，ω_u=(1,1) | 与 θ~U(0,1] 一致（可做 [0,1.5] 敏感性分析） |
| 特征标准化 | 每个基特征 z-score 标准化 | 保证 L1/组罚的公平性 |
| Σx | R_{x,i,j} = a^\|i−j\|，a=0.5 | 沿用 RWSL 论文协方差结构 |
| δ 缩放（精度实验） | 式 (10) 乘系数 c，使 corr(y, η_obs) ≈ 0.85/0.7/0.5 | 论文 §IV-B 三档物理精度 |

## 7. 设计合理性检验清单

基函数实现后，按以下清单自检：

1. **蒸馏保真度**：用 θ 真值生成 N=100 个物理样本，仅拟合蒸馏项 min_g λ₁‖H₂g−η̃‖² → H·g 对 η_obs 的 R² 应较高（若远低于 0.8，说明 H 库覆盖不足，需增补特征）；
2. **仿射合法性**：检查每个 H 特征关于 θ 的次数 ≤ 1；
3. **组结构**：len(groups) == q1+q3 == 5，且组内特征同源；
4. **可辨识性**：H 与 B 的列空间相关度检查（如典型相关分析 CCA），最高典型相关系数显著 < 1；
5. **锚点复现**：按 [07 §5](07_PWL复现指南.md) 的验证锚点核对（案例 B 的 MSE≈0.206、+233.3% 标签节省等）。

## 9. 一句话总结

> **基函数设计的本质，是把"物理模型的输入签名"翻译成"可优化、可辨识、可稀疏选择的模式库"**：H 按 η 的输入 (x^ph,θ) 构造以打通蒸馏通道，B 按完整可测变量 (x^pr,x^ph) 构造以补偿物理模型之不足，θ 以仿射方式入基以保住 ADMM 的闭式更新，分组按输入变量划分以匹配稀疏组 Lasso 的"同现象同进退"语义——四者共同使"物理知识 → 弱标签 → 预测精度"的转化在数学上闭合。
