## 1. 注释标签

核心代码使用以下标签：

| 标签 | 含义 |
|---|---|
| `[PAPER]` | 论文正文或补充材料明确描述的模型、公式、算法或实验协议 |
| `[INFERRED]` | 论文给出原则，但未公开具体实现；当前工程根据公式或算法约束补全 |
| `[STABILITY]` | 为避免奇点、溢出、病态矩阵或假收敛而增加；不是论文原始内容 |
| `[ENGINEERING]` | 并行、日志、结果制品、质量检查等工程增强，不属于论文算法 |

一个代码块可以同时具有两个属性。例如：

```text
[PAPER] 使用 H(x_ph, theta)
[INFERRED] H 的 25 个具体列由当前复现设计
```

---

## 2. 最重要的结论

当前实现保留了论文的核心数学结构：

```text
y = H(x_ph, theta)g + B(x_pr, x_ph)d + epsilon
```

以及论文式（5）的四类核心项：

```text
标记数据损失
+ 物理弱标签损失
+ L1 稀疏
+ 分组 L2 稀疏
```

但默认配置不是“纯论文模式”。以下六项是最可能影响与论文数值一致性的非公开设置或修改：

1. 25 维 `H` 和默认 3 维 `B`；
2. 输入协方差 `Sigma[i,j]=0.9^|i-j|`；
3. `reject_near_pole` 奇点拒绝采样；
4. `d_ridge=10`，直接在论文目标上增加了 `d` 岭项；
5. `physics_noise_fraction=0.25`；
6. `physics_one_standard_error` 超参数选择规则。

因此，当前结果应称为：

> 保持论文核心模型与优化骨架、对未公开设置作显式补全，并加入数值稳定措施的结构性复现。

### 论文未公开、当前补全

| 代码内容 | 类型 | 影响 |
|---|---|---|
| Toeplitz 协方差 | `[INFERRED]` | 改变输入和输出分布 |
| 默认相关系数 `0.9` | `[INFERRED]` | 使 IV-B 的 0.85 目标可达 |

### 为正常运行增加

| 代码内容 | 类型 | 影响 |
|---|---|---|
| `_signed_floor(...,1e-8)` | `[STABILITY]` | 极点附近改变公式值 |
| 指数裁剪到 `[-60,60]` | `[STABILITY]` | 避免 `exp` 溢出 |
| `reject_near_pole` | `[STABILITY]` | 把原正态分布变为条件分布 |
| 对整个 `theta2∈[0,1]` 检查式（9）分母 | `[STABILITY]` | 防止校准过程中跨越极点 |

### 特别注意

`paper_raw` 只关闭拒绝采样，不会关闭 `_signed_floor` 和指数裁剪。因此它是“更接近论文公开抽样”的模式，不是严格数学上的无保护实现。

## 3.2 `features.py`

文件：[features.py](../src/pwl_repro/features.py)

### 论文中已经描述

- 联合模型中存在 `H(x_ph,theta)` 和 `B(x_pr,x_ph)`；
- `H` 与物理模型共享输入；
- `g` 使用 L1 与组 Lasso；
- 分组数与 `q1+q3` 对应；
- `theta` 更新必须形成可解的子问题。

### 当前复现补全

| 代码内容 | 类型 | 说明 |
|---|---|---|
| 25 维 `H` | `[INFERRED]` | 论文未公布具体列 |
| 五组具体列索引 | `[INFERRED]` | 按 `x1,x2,x3,theta1,theta2` 构造 |
| 3 维紧凑 `B` | `[INFERRED]` | 精确张成式（11） |
| 12 维扩展 `B` | `[INFERRED]` | 用于差异补偿敏感性分析 |
| `H/B` z-score 标准化 | `[STABILITY]` | 改变相同数值 lambda 的有效强度 |
| 比值分母 `1e-8` 保护 | `[STABILITY]` | 避免除零 |

### 补充材料维度处理

代码将：

```text
H(x,theta)g
```

整理为：

```text
c(x,g) + G(x,g)theta
```

论文提供了仿射 `theta` 近端思路，但当前 `n×2` 的具体整理用于消除补充材料中的维度含混，属于 `[INFERRED]`。

## 5. 哪些修改会实质改变论文结果

### 高影响

1. **奇点拒绝采样**：改变输入分布；
2. **`rho=0.9` 协方差**：改变变量相关性和任务难度；
3. **具体 `H/B`**：改变模型表达能力；
4. **`d_ridge=10`**：直接改变目标函数；
5. **物理噪声比例**：改变弱标签可信度；
6. **一标准误差选参**：改变最终选择的超参数。

### 中等影响

- 特征和输出标准化；
- 独立参考总体 SNR；
- IV-B 校准方法；
- 嵌套数据池；
- 不合并训练与验证集；
- 未收敛候选过滤。

### 不应改变数学结果

- 多进程并行；
- 日志；
- CSV/JSON/图表生成；
- 质量检查；
- 统计报告；
- Windows ASCII 临时目录。

## 6. 接近论文形式的配置

可以用以下设置移除部分非论文稳定化：

```yaml
simulation:
  singularity_policy: paper_raw

model:
  d_ridge: 0.0
  selection_rule: minimum
  admm_adaptive_rho: false
  n_jobs: 1
```

但这仍不能称为作者原始配置，因为以下信息没有公开：

- 作者实际 `H/B`；
- `Sigma_x`；
- 物理噪声方差；
- 完整超参数网格；
- ADMM/BCD 数值设置；
- 奇点处理方法；
- 基线的完整调参细节。

此外，`paper_raw` 可能重新产生极端值、溢出趋势和训练失败，只适合作为敏感性对照，不应覆盖稳定版本结果。
