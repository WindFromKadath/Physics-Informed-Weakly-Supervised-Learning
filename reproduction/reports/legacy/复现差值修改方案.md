## 1. 背景与问题定义

当前工程已经实现论文式（9）–（11）的数据生成、PWL 的 `H g + B d` 联合模型、`g -> d -> theta` 的 BCD 主循环、 consensus ADMM、三类 Section IV 仿真实验、结果 CSV、质量检查和图表输出。

当前实际存在的一次完整 `7^3` 网格结果为单次重复，主要差值如下：

| 实验 | 当前结果 | 论文结果 | 当前判断 |
|---|---:|---:|---|
| IV-A，10 标签 PWL RMSE | 3.416 | 2.298 | 方向合理但绝对值偏高 |
| IV-A，60 标签 PWL RMSE | 2.255 | 1.619 | 方向合理但绝对值偏高 |
| IV-A，120 标签 PWL RMSE | 2.185 | 1.378 | 已接近当前噪声下限，但高于论文 |
| IV-B，PWL-H RMSE | 1.969 | 1.392 | 偏高 |
| IV-B，PWL-M RMSE | 3.506 | 2.054 | 单次运行异常偏高 |
| IV-B，PWL-L RMSE | 2.010 | 2.404 | 单次运行低于论文，但排序失败 |
| IV-C，30 标签 PWL MSE | 6.375 | 3.745 | 明显偏高 |
| IV-C，110 标签监督-PWL 差值 | +4.673 | 论文已交点/反超 | 未复现交点 |

最关键的尺度证据是：当前 `conditions.csv` 中 `noise_sigma = 2.1585`，对应噪声方差约 `4.659`；当前 120 标签 PWL 的 MSE 为 `4.775`，已经接近当前数据生成过程的不可约误差。论文 120 标签 PWL 的 RMSE 为 `1.378`，对应 MSE 约 `1.899`。因此，当前结果与论文的绝对差值首先应被怀疑为**数据分布/信号尺度/噪声尺度不一致**，而不是单纯优化失败。

## 2. 修改目标

### 2.1 总目标

建立一套可审计、可回滚、单因子可控的修改与实验流程，判断当前差值主要来自哪一类原因：

1. 论文未公开的数据生成设置；
2. 当前显式稳定化假设；
3. 当前基函数与真实作者基函数不一致；
4. 当前目标函数或模型选择规则偏离论文文字；
5. 当前实验重复数不足导致的随机波动；
6. 监督基线调参/重训协议不一致。

### 2.2 具体目标

- 把当前基线冻结，避免后续调参覆盖已有证据；
- 增加论文数值对照和噪声归一化指标；
- 增加 PWL 内部诊断，区分“蒸馏不足”“补偿不足”“选参偏差”“数据尺度偏差”；
- 用一组小规模敏感性配置逐项测试高影响假设；
- 在趋势稳定后再运行 20 次重复；
- 最终明确哪些结果可以称为论文趋势复现，哪些只能称为当前假设下的结构复现。

### 2.3 非目标

- 不通过无记录调参强行贴合论文数值；
- 不把当前补全配置称为作者原始配置；
- 不修改或覆盖现有 `section_iv_single_full_parallel` 结果；
- 不在缺少案例数据时强行复现真实案例 Table III–VI。

---

## 3. 修改原则

1. **一次只改一个因子**：先分离数据生成、模型结构、目标函数、选参规则、基线协议的影响；
2. **默认行为不变**：核心代码新增功能默认关闭，现有配置结果应保持不变；
3. **所有假设显式化**：继续沿用 `[PAPER]`、`[INFERRED]`、`[STABILITY]`、`[ENGINEERING]` 标签；
4. **先诊断后全量**：先 smoke，再 5 次诊断，再 20 次重复，最后才完整网格；
5. **用归一化指标判断**：除 RMSE/MSE 绝对值外，同时比较 `MSE / noise_variance`；
6. **失败也保留证据**：IV-B 排序失败、IV-C 无交点、候选不收敛都必须写入结果，不手工掩盖。

新增脚本：

```text
reproduction/scripts/diagnose_basis.py
```

针对同一组数据分别计算：

1. 仅使用 `H(x_ph, theta_true)` 对 `eta_true` 的最小二乘 R²；

4. `compact B` 与 `expanded B` 对 `discrepancy` 残差的吸收能力；
5. `H` 与 `B` 列空间的最大典型相关系数。

### 5.3 验收标准

## 7. 阶段 3：单因子实验执行顺序

### 7.1 第一轮：训练规则类

优先运行：

1. `s01_minimum_selection.yaml`；
2. `s02_no_d_ridge.yaml`；
3. `s04_refit.yaml`；
4. `s12_paper_text_combo.yaml`。

判断：

- 如果 IV-B 明显改善，说明当前一标准误差物理优先规则或 `d_ridge` 是重要因素；
- 如果 IV-C 交点提前，说明基线重训协议是重要因素；
- 如果结果变得不稳定，说明当前稳定化项确实是必要补全。

### 7.2 第二轮：模型结构类

运行：

1. `s03_expanded_b.yaml`；
2. `s10_linear_mapping.yaml`。

判断：

- 如果 IV-B 的 M/L 档明显改善，说明紧凑 `B` 不能吸收物理差异是主因之一；
- 如果整体 RMSE 下降但排序不变，说明模型尺度问题仍在；
- 如果线性 `phi` 改善 H 档但不改善 L 档，说明物理映射偏差不是唯一问题。

### 7.3 第三轮：数据生成类

运行：

1. `s05_corr_05.yaml`；
2. `s06_corr_07.yaml`；
3. `s07_physics_noise_00.yaml`；
4. `s08_physics_noise_01.yaml`；
5. `s09_physics_noise_05.yaml`；
6. `s11_paper_raw.yaml`。

判断：

- 如果归一化指标不变但绝对 RMSE 大幅变化，说明主要是数据尺度问题；
- 如果 IV-B 目标相关性无法达到，说明当前 `rho=0.9` 是可达性假设；
- 如果 `paper_raw` 出现大量无效候选或极端 RMSE，说明奇点处理是论文缺失但不可回避的问题；
- 如果物理噪声变化显著改变 IV-B，说明论文未公开的物理噪声方差是高敏感参数。

## 9. 质量门槛与判定标准

### 9.1 数值门槛

所有运行必须满足：

- 测试指标有限；
- 被选中 PWL 收敛率 >= 95%；
- 无效候选比例 <= 25%，或明确解释为何放宽；
- IV-B 最大校准相关性误差 <= 0.02；
- `paper_raw` 模式允许失败，但必须作为敏感性失败记录。

### 9.2 论文趋势门槛

| 实验 | 最低可接受趋势 | 理想结果 |
|---|---|---|
| IV-A | PWL RMSE 随标签增加整体下降 | 归一化曲线接近论文 |
| IV-B | 平均意义上 `PWL-H < PWL-M < PWL-L` | 20 次重复中排序稳定 |
| IV-C | 报告真实交点，不强行要求 100 标签 | 在当前假设下估计交点并明确标注 |

### 9.3 归因规则

| 观察结果 | 结论 |
|---|---|
| 改 `correlation` 或奇点策略后，归一化指标基本不变但绝对值大幅变化 | 主要是数据生成尺度差异 |
| 改 `selection_rule` 后 IV-B 明显改善 | 当前选参规则偏离论文文字是重要因素 |
| 改 `d_ridge=0` 后 IV-A/IV-B 改善但小样本不稳定 | 稳定项与论文目标之间存在权衡 |
| 改 `b_profile=expanded` 后 IV-B M/L 改善 | 紧凑 `B` 缺少物理差异补偿能力 |
| 改 `refit=true` 后 IV-C 交点提前 | 监督基线协议影响 IV-C |
| 所有单因子变化都无法缩小归一化差距 | 缺失作者 `H/B` 或 `Sigma_x` 是主要瓶颈 |

## 13. 当前最重要的一个判断

在修改代码前，必须先接受一个事实：当前 120 标签 PWL 已接近当前数据生成过程的噪声下限，因此它和论文之间的绝对 RMSE 差值不可能只通过调 ADMM 或增加迭代次数消除。后续修改的核心不是“让优化器更努力”，而是**找出论文未公开设置中哪一个改变了任务尺度、物理信息质量或模型表达能力**。
