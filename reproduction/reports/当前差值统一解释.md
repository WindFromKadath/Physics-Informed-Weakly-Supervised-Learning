# 当前复现差值的统一解释

> 更新日期：2026-07-30  
> 状态：替代先前分散猜想  
> 适用对象：PWL Section IV 仿真实验复现

---

## 1. 统一表述

当前复现结果与论文之间仍然存在差值，不应再解释为一组相互独立、可继续逐个调参消除的工程猜想。基于已经完成的单因子敏感性实验，剩余差值应统一表述为：

> **作者真实实验设置未知，导致当前复现的数据生成任务和函数逼近任务与论文原实验在结构上不一致。最关键的未知项是作者实际使用的 `H/B` 基函数，以及这些基函数与输入协方差、奇点处理和噪声尺度共同决定的任务难度。**

更直接地说：

> **当前差值不是某个局部工程参数没调好，而是当前复现很可能并不是在与论文完全相同的任务上训练。**

在缺少作者代码、作者 `H/B`、真实 `Sigma_x` 和奇点处理规则时，继续调整 ADMM 参数、物理噪声比例、模型选择规则、`d_ridge`、紧凑/扩展 `B`、是否合并验证集等工程设置，都不应被期待能消除论文与当前复现之间的绝对数值差。

---

## 2. 已经不再作为主要差值来源的猜想

以下猜想已经通过配置对照或结果审计被排除为主要解释：

| 先前猜想 | 当前判断 |
|---|---|
| 物理噪声默认值 `physics_noise_fraction=0.25` 导致差值 | 不成立。降到 0 后只能解释约 0–5% 的论文差值，IV-B M/L 反而变差 |
| 输入协方差 `rho=0.9` 导致论文数值更低 | 不成立。`rho=0.5/0.7` 的结果更差，且 IV-B 的 0.85 目标不可达 |
| 奇点拒绝采样是主要误差来源 | 不成立为主要解释。`paper_raw` 会产生极端值和 RMSE 爆炸，说明奇点处理不可回避 |
| `selection_rule=physics_one_standard_error` 是主因 | 不成立。改为最低验证 MSE 后没有稳定改善，小样本反而病态 |
| `d_ridge=10` 是主因 | 不成立。设为 0 后 IV-B-H 略好，但 IV-A 小样本和 IV-B M/L 变差 |
| 紧凑 `B` 是主因 | 不成立。扩展 `B` 没有带来稳定改善，且与 `H` 列空间高度重叠 |
| 不合并训练/验证集是 IV-C 主因 | 不成立。`refit=true` 是稳健改进，但 IV-C 仍无论文式交点 |
| ADMM/BCD 收敛或并行实现是主因 | 不成立。选中模型收敛率、有限性和串并行一致性均未显示其能解释绝对差值 |

这些设置仍然需要保留为可审计假设，但不应再继续作为“差值可能由它导致”的主要解释。

## 3. 当前证据支持的统一判断

### 3.1 当前任务本身更接近自己的噪声下限

当前健康变体中，120 标签 PWL 的 `mse/noise_variance` 大致维持在 `1.06–1.20` 区间。也就是说，当前模型已经接近当前数据生成过程允许达到的下限。

论文 120 标签 PWL 的 MSE 约为 `1.899`，明显低于当前数据生成过程的噪声方差尺度。这说明论文原实验的任务尺度或噪声尺度与当前复现不同。

### 3.2 改变已测工程参数不能缩小归一化差距

敏感性实验覆盖了：

- 物理噪声：`0 / 0.10 / 0.25 / 0.50`；
- 输入协方差：`0.5 / 0.7 / 0.9`；
- 奇点策略：`reject_near_pole / paper_raw`；
- 选参规则：最低验证 MSE / 物理优先一标准误差；
- `d_ridge`：`0 / 10`；
- `B`：紧凑 / 扩展；
- `phi`：恒等 / 线性；
- 选参后是否合并训练与验证集。

没有任何一个健康变体能同时显著缩小 IV-A、IV-B、IV-C 与论文的归一化差距。

### 3.3 `theta` 边界命中显示结构性参数化不一致

当前仿射 `H` 模型在绝大多数条件下都把校准参数推向盒约束边界。这不是普通调参问题，而是当前 `H(x_ph, theta)` 对真实物理参数化的表达与作者实验不一致的信号。

### 3.4 IV-C 的差异也指向任务定义，而不是协议实现

在所有健康变体中，30 标签 PWL 都持续优于 110 标签内的最佳监督模型，没有出现论文中的 100 标签等效交点。这说明当前数据生成条件下 PWL 的标签节省效应比论文更强。该现象与“任务定义不同”一致，而不是 IV-C 代码没有执行论文协议。

## 4. 后续报告中的统一写法

后续所有报告、论文复现说明或答辩材料中，建议统一使用以下表述：

> 当前工程实现了论文公开的 PWL 模型结构、BCD–ADMM 优化骨架和 Section IV 实验协议，但论文未公开作者实际使用的 `H/B` 基函数、输入协方差、物理噪声和有理函数奇点处理方式。单因子敏感性实验表明，已测试的工程补全设置均不能解释当前与论文之间的主要数值差。因此，剩余差值应归因为作者真实实验设置未知所导致的结构性任务差异，而不是某个局部实现参数尚未调优。

如果需要更短的一句话版本：

> **当前复现与论文的剩余差值，主要来自未知的作者实验设置所定义的不同学习/数据生成任务，而不是当前代码中某个可调的工程参数。**

---

## 5. 仍然有价值的下一步

只有两类下一步仍有实际意义：

1. **获取作者原始材料**：作者代码、`H/B` 基函数、`Sigma_x`、物理噪声、奇点处理规则、完整调参网格；
2. **把基函数/数据生成空间搜索作为独立研究问题**：系统比较不同 `H` 分组、次数、有理特征、`B` 与 `H` 正交化设计和输入分布，而不是继续微调已经测试过的工程参数。

在这些材料或新研究完成前，当前结果应表述为：

> **结构性复现 + 敏感性审计完成；不是论文绝对数值复现。**
