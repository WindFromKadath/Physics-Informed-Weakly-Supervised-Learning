# PWL 算法真实能力与信息边界审计

> 日期：2026-08-05  
> 状态：方法真实性审计稿；用于重新界定结论，不替代尚未完成的独立确认实验  
> 审计对象：热传导迁移场景中的 PWL A0/A1/A3、直接机理对齐回归 A4，以及相关 A0–A4 小范围实验  
> 核心问题：当前结果究竟反映了 PWL 框架本身的能力，还是反映了研究者已经知道主要误差机理后进行特征设计的能力？

---

## 0. 最终判断

当前项目**没有发现训练程序直接读取验收标签的代码级数据泄漏**，因此不能把现有
实现简单定性为“程序作弊”。但是，从科学评价角度看，当前实验确实存在明显的
**特权机理信息使用**和**验收集参与研究设计**问题：

1. 当前最强 PWL 配置的差异库中含有
   `q_int*P^(-0.7)` 和
   `q_int/(1+hL/k_nominal)*P^(-0.7)`；
2. 其中 `P^(-0.7)` 与高保真数据生成器中的接触热阻规律
   `R_c(P)=0.03P^(-0.7)` 直接对应；
3. A4 又把低保真输出、界面热流和同一个精确指数直接组合成仅 4 个系数的回归；
4. M0–M3 输出对齐诊断查看了现有 20 批验收集上的结果，随后提出 A4，再在其中
   批次 1–5 的同一验收集上比较 A0–A4。

因此，当前证据能够支持的结论是：

> **当主要模型偏差机理及其函数形式已被研究者基本知道时，PWL 可以把这些知识写入
> 差异基函数并获得约 5 K 的预测误差；但这不是 PWL 自动识别未知物理模型误差的
> 证据。当前热场景的最好结果应称为“机制辅助型 PWL”的结果。**

当前证据不能支持以下更强结论：

- PWL 能从不准确物理模型中自动发现未知偏差机理；
- `Q*P^(-1/2)`、`q_int*P^(-0.7)` 等具体项可以直接迁移到其他物理场景；
- PWL 已经在独立测试意义下优于全部强基线；
- A4 证明了直接机理对齐在一般未知机理场景中有效。

“作弊嫌疑”更准确的学术表述应为：

> **当前模型设计受到了数据生成真值机理和既有验收结果的辅助，存在特权信息辅助建模
> 与测试集引导的研究过拟合风险。它不是直接标签泄漏，但会高估方法对未知物理误差
> 的可迁移能力。**

## 1. 当前被预测的物理量

当前输出 `y` 是双层结构在 `z=50 mm` 界面两侧温度的平均值：

```text
y = [T(50 mm^-) + T(50 mm^+)] / 2
```

它不是 `z=0 mm` 与 `z=100 mm` 两端温度的平均值。高保真模型包含温度相关导热率
和压力相关接触热阻；低保真模型使用固定名义导热率并假设界面完全接触。因此，两者
输出语义和单位相同，但存在显著的尺度偏差和随压力、热流变化的结构偏差。

当前低保真直接输出在 20 批诊断中的验收 RMSE 约为 `15.276 K`，而测量噪声标准差
为 `4.494 K`。这说明低保真模型具有趋势相关性，但绝对预测明显失配。

## 2. 必须区分的三个对象

### 2.1 PWL 通用框架

当前实现所对应的抽象结构是：

```text
y_hat = H(x_ph, theta) g + B(x_ph, x_pr) d
```

其中：

- `H(x_ph,theta)g` 用有限维基函数吸收低保真物理趋势；
- `B(x_ph,x_pr)d` 描述物理模型与真实系统之间的差异；
- 弱标签用于约束模型不要在小样本下完全偏离低保真趋势；
- 稀疏和组正则用于控制候选差异项的复杂度。

这个优化框架本身是可实现、可训练、可做消融的。框架允许研究者更换 `H`、`B`、
输出映射 `phi` 和正则化规则。

但必须注意：**框架允许候选项被筛选，不等于框架能自动发明候选项。** 如果真实偏差
方向没有进入 `B`，稀疏回归不可能选择一个根本不存在的机理。

### 2.2 当前热场景的 PWL 实例

当前 A0/v3 使用 `identity` 输出映射和包含下列项的差异库：

```text
[1, P, 1/P, P^(-1/2), Q/P, Q*P^(-1/2),
 q_int*P^(-0.7), q_int/(1+hL/k_nominal)*P^(-0.7)]
```

其中前六项是较宽松的工程候选，后两项则直接针对接触热阻造成的界面温度跳变。
所以当前配置不是“只给一个不准确低保真模型，让 PWL 自己找出误差”的实验，而是：

```text
低保真趋势 + 人工给定的误差机理候选 + 稀疏估计
```

更准确的名称是：

> **机制辅助型 PWL（mechanism-assisted PWL）**

### 2.3 A4 直接机理对齐回归

A4 使用：

```text
y - T0 = alpha + beta*(y_LF - T0)
         + c1*q_int*P^(-0.7)
         + c2*q_int/(1+hL/k_nominal)*P^(-0.7)
```

它在训练折上用普通最小二乘估计 4 个系数，不使用弱标签，也不进行 PWL 的块坐标
迭代。A4 是一个透明、低方差的**灰盒机理校准模型**，不是 PWL。

A4 的优势来自两部分：

1. 直接使用完整的低保真输出 `y_LF`，没有先把物理输出近似蒸馏到有限 `H` 基底；
2. 已经知道主要残差是“界面热流 × 压力相关接触热阻”的形式。

因此，A4 适合作为当前已知机理条件下的强基线或近似 oracle 上界，但不能作为
“面对未知误差也能自动对齐”的通用方法证据。

## 3. 现有测试内容与结果

### 3.1 A0–A4 实验臂

| 实验臂 | 模型结构 | 主要目的 | 信息强度 |
|---|---|---|---|
| A0 | identity + v3 qint PWL | 当前冻结 PWL 主配置 | 含精确机理项 |
| A1 | linear `phi` + v3 qint PWL | 检查全局线性输出对齐 | 含精确机理项 |
| A2 | linear `phi` + 截距 B | 检查只做全局对齐是否足够 | 不含条件机理 |
| A3 | linear `phi` + no_qq B | 检查移除 qint 精确机理列后的变化 | 工程候选项 |
| A4 | 温升仿射 + 两列 qint OLS | 已知机理下的直接校准强基线 | 最强机理先验 |

### 3.2 五批方向性结果

| 实验臂 | @10 RMSE | @60 RMSE | @120 RMSE |
|---|---:|---:|---:|
| A0 | 8.551 K | 5.870 K | 5.410 K |
| A1 | 8.200 K | 5.917 K | 5.550 K |
| A2 | 9.777 K | 7.987 K | 7.869 K |
| A3 | 8.303 K | 6.055 K | 5.689 K |
| A4 | 8.295 K | 5.052 K | 4.789 K |
| 噪声标准差 | 4.494 K | 4.494 K | 4.494 K |

这些结果说明：

- 给完整 PWL 加一次性线性 `phi` 没有带来稳定收益，A1 在 @120 反而比 A0 高
  `0.140 K`；
- 只做全局线性对齐而不建模条件偏差明显不够，A2 的 @120 仍为 `7.869 K`；
- 移除两列精确 `q_int` 项后，A3 比 A1 差 `0.139 K`，表明这些项确实提供了
  有效方向；
- A4 在 @120 比 A0 低 `0.621 K`，并接近噪声下限；
- A4 在 @10 并不优于 A1，原因之一是只有 7 个训练点却估计 4 个系数，方差较大。

### 3.3 二十批冻结结果的边界

当前 A0 在 20 批、@120 下的平均 RMSE 为 `5.351 K`。既有最强基线
Physics-GP 为 `5.648 K`，GP 为 `5.680 K`。A0 的均值较低，但相对
Physics-GP 的优势没有通过当前 Holm 多重校正门槛（校正后约 `p=0.071`）。

因此，即便暂时不考虑特权机理问题，现有 20 批结果也只能写成：

> A0 在当前基线集合中取得最低平均 RMSE，但尚无充分的多重校正后统计证据证明
> PWL 稳定优于最强基线。

### 3.4 代码测试已经证明什么

现有单元测试覆盖了：

- A4 的实现与手工 OLS 计算一致；
- A4 只使用训练折拟合，验证集和验收标签不进入系数估计；
- 线性 `phi` 只在训练折拟合；
- 温升形式与绝对温度形式等价；
- `q_int` 两列的数值实现与独立公式计算一致；
- A0–A3 使用相同批次、嵌套划分和验收样本，可进行配对比较。

这些测试能够排除明显的**执行级标签泄漏**，但不能排除：

- 研究者先知道高保真生成器的精确公式，再设计 `B`；
- 研究者观察验收结果后继续发明模型结构；
- 在同一批验收集上反复比较版本所产生的研究过拟合。

单元测试保证“代码按设计工作”，不保证“实验设计在科学上独立”。

## 4. “作弊嫌疑”的分级审计

为避免非黑即白地使用“作弊”一词，本项目采用以下分级。

| 等级 | 含义 | 是否允许形成正式泛化结论 |
|---|---|---|
| L0 | 使用部署时真实可获得的输入、低保真模型和训练标签 | 可以 |
| L1 | 使用实验前声明的宽泛工程先验，如单调性、平滑性、量纲关系 | 可以，但必须预注册 |
| L2 | 使用与隐藏真值生成器高度一致的函数形式或精确指数 | 只能形成条件性/机制已知结论 |
| L3 | 查看测试或验收表现后再选择特征、模型或结论 | 只能作开发诊断，必须换新测试集确认 |
| L4 | 训练过程直接读取测试标签或按测试标签调参 | 无效实验 |

### 4.1 当前项目逐项判定

| 项目内容 | 等级 | 判定 |
|---|---:|---|
| 使用 `Q,h,T_inf,P` 作为输入 | L0 | 合法；部署时可观测 |
| 使用低保真闭式解和名义 `k=25` | L0 | 若部署时确实可调用，则合法 |
| 使用 `P`、`1/P`、低阶交互等宽泛候选 | L1 | 可作为预先声明的工程字典 |
| 使用 `P^(-1/2)`、`Q*P^(-1/2)` | L1–L2 | 已假设负幂和乘性结构；不是场景无关基函数 |
| 使用 `q_int*P^(-0.7)` 两列 | L2 | 与隐藏接触热阻真值形式直接对齐，近似 oracle 特征 |
| A4 使用同样两列并直接回归 | L2 | 合法的已知机理灰盒基线，但不是未知机理方法 |
| 系数只由训练折估计 | L0 | 当前测试已确认，没有直接测试标签泄漏 |
| M0–M3 查看 20 批验收表现后提出 A4 | L3 | 只能视为开发性发现 |
| A4 再使用批次 1–5 的相同验收集比较 | L3 | 数值可做方向判断，不能作为独立确认 |
| 训练函数直接使用验收标签 | L4 | 当前未发现 |

### 4.2 为什么 `Q*P^(-1/2)` 也不是完全通用

`Q*P^(-1/2)` 隐含了三个判断：

1. 热源强度与偏差近似乘性耦合；
2. 压力对偏差呈负幂影响；
3. 指数接近 `-1/2`。

它比精确的 `P^(-0.7)` 更宽松，但仍然是面向接触传热问题的工程特征。它可能迁移到
同类接触导热、电接触或压力控制界面问题，却不能直接迁移到辐射、相变、流固耦合、
化学反应等误差机理不同的场景。

真正可迁移的是以下方法过程，而不是该公式本身：

```text
根据可公开获得的工程知识提出候选方向
→ 只用训练/验证数据选择复杂度
→ 在未触碰的新测试系统上验证
```

## 5. 当前 PWL 的真实水平应如何描述

### 5.1 已经得到支持的能力

当前实验支持以下能力判断：

1. PWL 框架能够联合低保真趋势、少量真实标签和显式差异字典；
2. 当主要差异方向已经进入 `B` 时，稀疏估计可以利用这些方向；
3. 在当前构造热场景中，机制辅助型 PWL 将直接物理模型约 `15.3 K` 的误差降低到
   约 `5.35 K`；
4. 差异补偿通道是必要的，只做全局输出比例校准不能解决压力相关跳变；
5. 当前 `theta` 更像预测校准的干扰参数，不能解释成被准确恢复的真实导热率。

### 5.2 尚未得到支持的能力

当前实验没有证明：

1. PWL 能在不知道主要偏差机理时自动构造有效 `B`；
2. PWL 对机理变化、模型形式错误或分布外压力规律具有稳定鲁棒性；
3. 弱标签本身是当前性能提升的主要来源；
4. PWL 比直接的灰盒校准更适合当前“低保真模型便宜且主要误差机理已知”的场景；
5. 当前特征库能够不经重新设计迁移到其他物理对象。

### 5.3 推荐的正式表述

论文或汇报中建议采用：

> 本研究实现了 PWL 的通用优化框架，并在双层接触传热场景中构造了一个机制辅助型
> 实例。该实例在候选差异库包含主要接触热阻方向时能够显著修正低保真模型，但当前
> 结果不能证明 PWL 能自动识别未知模型偏差。精确的压力指数和界面热流组合属于较强
> 机理先验，其跨场景可迁移性仍需通过信息隔离的盲测验证。

不建议继续使用：

> PWL 只依靠低保真相关性就能自动校正任意不准确物理模型。

## 6. A4 的有效性边界

A4 不是“无效方法”，但它的适用条件比表面上窄。

### 6.1 A4 合理的场景

A4 在以下条件下是很合理的工程方法：

- 主要残差机理已由理论、独立实验或领域知识确定；
- 只是不知道系数大小，而不是不知道函数结构；
- 低保真模型在线调用成本很低；
- 部署分布与标定分布一致；
- 目标是准确预测，而不是证明通用的未知机理学习能力。

在当前闭式低保真模型中，这些条件基本满足，所以 A4 比复杂 PWL 更好并不意外。

### 6.2 A4 不能代表的场景

如果现实中不知道：

- 接触热阻是不是幂律；
- 指数是不是 `-0.7`；
- 偏差是否与 `q_int` 成乘积；
- 高压区是否饱和、分段或出现迟滞；
- 温度相关导热率是否是主要误差来源；

那么 A4 的设计矩阵就无法被事先写出。此时 A4 不能被视为通用可部署方法，只能被
视为“如果主要机理已知，能够达到什么精度”的 oracle/灰盒参照。

### 6.3 A4 与 PWL 的部署合同并不完全相同

A4 预测时直接调用完整低保真闭式输出和 `q_int`；PWL 则试图把低保真趋势蒸馏到
`H/B` 中。当前低保真模型计算极便宜，所以 A4 的在线调用并不是缺点。未来如果
低保真模型是耗时 COMSOL 求解器、部署端不可调用或许可受限，PWL 的离线蒸馏才可能
产生额外价值。

因此 A4 优于 PWL 的当前结果应解释为：

> 在“机理较清楚且低保真计算便宜”的本场景中，直接灰盒校准比当前 PWL 实例更合适。

而不是：

> 直接机理对齐在所有物理模型不准确问题上都优于 PWL。

## 7. 真正评价 PWL 框架的盲测协议

仅把 A1–A3 从 5 批扩展到原有 20 批，不能解决独立性问题，因为这 20 批验收集已经
参与过诊断和模型设计。需要新建完全未触碰的系统级批次，例如批次 21–40，并在查看
任何新验收结果前冻结下列内容。

### 7.1 信息边界

开发模型时允许知道：

- 输入和输出的物理含义、单位、合理范围；
- 可部署的低保真方程或仿真器；
- 训练折真实标签和弱标签；
- 独立工程知识，如“压力影响可能单调”“偏差可能随热流增强”。

开发模型时禁止知道：

- 新批次高保真生成器中的真实接触热阻公式和指数；
- 新批次验收标签；
- 各候选模型在新验收集上的排名；
- 为新验收结果临时增加的基函数或超参数范围。

### 7.2 建议的三层 PWL 实验臂

| 层级 | 差异模型 | 目的 |
|---|---|---|
| G0：机理未知 | 归一化输入的低阶多项式、样条或通用交互；不含精确真值指数 | 测 PWL 框架的基础能力 |
| G1：工程先验 | 使用 `q_int*g(P)`，但 `g` 为单调样条或训练/验证内估计的幂指数 | 测宽泛物理知识的价值 |
| G2：oracle | 使用精确 `q_int*P^(-gamma_true)` | 只给出机理完全已知时的上界 |

必须同时比较：

- GP、Physics-GP 或其他强监督/残差学习基线；
- 直接低保真模型；
- 仿射输出对齐；
- A4 类型的 oracle 灰盒回归；
- 不使用弱标签的 PWL 消融。

### 7.3 机理变化测试

新的高保真系统不能只重复固定 `P^(-0.7)`，至少应包含研究者事先不知道具体取值的：

1. 不同幂指数 `gamma`；
2. 饱和规律，如 `(P+p0)^(-gamma)`；
3. 分段接触或压力阈值；
4. 温度依赖的接触热阻；
5. 不存在界面跳变、但存在其他模型偏差的负对照；
6. 训练压力区间外的分布外测试。

只有这样才能回答 PWL 是在学习“偏差建模方法”，还是只在匹配一个已知的数据生成
公式。

### 7.4 防止再次发生测试集引导

推荐执行顺序：

```text
冻结问题定义、特征来源和比较模型
→ 保存配置与代码版本哈希
→ 生成或由第三方保管新批次
→ 训练/验证阶段不输出验收指标
→ 一次性解封验收集
→ 运行预先声明的统计检验
→ 无论结果好坏均报告
```

如果解封后继续改模型，旧验收集立即降级为开发集，必须再生成下一套未触碰验收集。

### 7.5 建议的主终点与判定

- 主终点：预先指定一个标签量（建议 @120）的批间配对 RMSE；
- 次终点：小样本区间 @10–60 的平均曲线面积或平均 RMSE；
- 同时报告 MSE/噪声方差比、批间符号一致率和置信区间；
- 预先定义一个多重检验族，不在看到结果后拆分 Holm 校正族；
- 新批次建议至少 20 个，并辅以配对置换检验或精确符号检验。

判定规则：

| 盲测结果 | 对 PWL 的解释 |
|---|---|
| G0/G1 在未知机理变化下稳定优于强基线 | 支持 PWL 框架具有真实迁移能力 |
| 只有 G2/oracle PWL 优于基线 | PWL 仅在主要机理已知时有效 |
| A4/oracle 优于全部 PWL | 当前场景更适合直接灰盒校准 |
| G0/G1 与 GP 相当 | PWL 可作有结构备选，但不能声称优势 |
| G0/G1 明显差于 GP | 当前 PWL 对不准确且未知的物理模型不适合 |

## 8. 对当前结果的处理建议

### 8.1 可以保留

- A0–A4 的现有数值和图表；
- 代码级防泄漏测试；
- PWL 结构、求解和消融实验；
- 当前热模型作为“机理已知程度较高”的示范案例；
- A4 作为已知机理强基线。

### 8.2 必须降级表述

- A0–A4 五批结果标记为**开发性/方向性证据**；
- M0–M3 的 20 批验收结果标记为**模型设计诊断**；
- `q_int*P^(-0.7)` 标记为**oracle/强机理先验特征**；
- A0 的 `5.351 K` 标记为**机制辅助型 PWL 的冻结结果**；
- “PWL 最优”改为“在既定比较集合中的均值结果”，并附多重校正未通过事实。

### 8.3 不能继续作为主证据

- 在原批次 1–20 上继续增加新特征并把改善当成独立泛化证据；
- 用 A4 接近噪声下限证明一般性的输出对齐能力；
- 用精确指数项的成功证明 PWL 自动发现了接触热阻规律；
- 忽略 A4 使用完整低保真调用而 PWL 使用蒸馏表示的部署差异。

## 9. 一句话结论

> **当前 PWL 实现展示的是“已知主要误差机理后，PWL 如何利用机理特征”的水平，
> 而不是“面对一个机理不明的不准确物理模型，PWL 能否自行完成有效迁移”的水平；
> 现有结果没有直接标签泄漏，但存在足以影响论文结论的特权机理和测试集引导风险。**
