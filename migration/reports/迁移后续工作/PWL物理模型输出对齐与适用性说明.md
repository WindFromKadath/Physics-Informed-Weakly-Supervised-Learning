# PWL 物理模型输出对齐与适用性说明

## 0. 结论摘要

当前热传导场景的低保真输出与高保真真实标签之间，确实存在显著的**模型输出
对齐问题**。当前主配置采用 `mapping: identity`，即没有先对低保真输出进行
显式比例和截距校准。

基于现有 20 批数据的只读诊断表明，在每批使用前 84 条参考数据拟合、并在
200 条独立验收数据上评估时：

| 诊断模型 | 20 批平均验收 RMSE（K） |
|---|---:|
| 原始低保真输出（identity） | 15.276 |
| 仿射对齐 `a + b*y_LF` | 8.026 |
| 仿射对齐 + `P^(-0.7)` | 6.214 |
| 仿射对齐 + 两列 `q_int` 机理项 | 4.763 |
| 当前 PWL（20 批正式结果） | 5.351 |
| 测量噪声 RMSE 下限 `sigma` | 4.494 |

因此，当前误差不能只解释为“物理相关性不足”，而应分解为：

1. 全局比例和偏移误差，可由论文中的输出映射 `phi` 处理；
2. 随 `P/Q/h/T_inf` 变化的条件结构偏差，必须由 `B(x)d` 或等价的机理修正处理；
3. 测量噪声与有限标签估计误差。

当前场景的合理建模结构应为：

```text
低保真输出 --phi：全局尺度对齐--> 已对齐物理趋势
                                      +
过程变量 --B：条件偏差补偿-------> 真实系统预测
```

本诊断还暴露出一个重要实验缺口：简单的“仿射对齐 + 两列 `q_int` 机理项”诊断
结果低于当前 PWL RMSE。该结果尚未进入冻结协议，不能直接替代正式结论，但说明
后续必须把它加入强基线；在此之前，“PWL 最优”只能表述为**在当前既有基线集合
内均值最优**。

---

## 1. 问题定义：什么是模型对齐

物理模型输出与真实标签之间可能存在三类不同关系，必须分别处理。

### 1.1 语义对齐

物理模型与真实标签测量的不是同一个量，例如物理模型输出温度，而真实标签是
质量等级。此时需要映射：

```math
y \approx \phi(eta).
```

当前热传导场景**不存在输出语义不一致**：高、低保真模型的输出都定义为
`z = L/2 = 50 mm` 界面两侧温度的平均值，单位均为 K。

### 1.2 全局尺度对齐

即使输出语义和单位相同，低保真模型仍可能因缺少热阻或材料非线性而产生近似的
比例和偏移关系：

```math
y_HF \approx a + b y_LF.
```

这属于统计校准意义上的 `phi`，并不代表两个模型测量了不同物理量。

### 1.3 条件结构偏差

若残差还依赖过程变量，则一维映射 `phi(y_LF)` 不足：

```math
y_HF = phi(y_LF) + Delta(Q,h,T_inf,P) + epsilon.
```

当前场景的主要条件偏差来自界面接触热阻：

```math
R_c(P) = R_0 P^{-0.7},
```

```math
Delta T_int = q_int R_c(P).
```

低保真模型令 `R_c = 0`，因此完全不响应 `P`。两个样本即使具有相同的
`y_LF`，也可能因为 `P` 不同而具有不同的 `y_HF`。任何只依赖 `y_LF` 的
全局映射都无法消除这部分误差。

## 2. 当前实现状态

当前热传导主配置：

```yaml
model:
  mapping: identity
```

对应：

```math
phi(y_LF) = y_LF.
```

核心估计器已经支持可选的一维线性映射：

```math
phi(y_LF) = a + b y_LF,
```

其中 `a/b` 仅使用传入 `fit` 的标记训练数据估计。在线性映射启用时，物理弱标签
会先经过 `phi`，再进入物理弱监督损失。当前迁移配置没有启用该路径。

当前 PWL 仍能通过 `H` 的截距和系数、以及 `B` 的差异项隐式吸收部分对齐误差，
但这会造成角色混合：

- `H` 同时承担低保真规律蒸馏与真实尺度调整；
- `B` 同时承担全局偏移与界面机理补偿；
- 强物理权重下，原始弱标签尺度与真实标签尺度之间可能产生正则张力。

显式 `phi` 的目的，是先消除低阶尺度差异，使 `B` 更集中地描述输入相关偏差。

## 3. 20 批只读诊断

### 3.1 数据与隔离规则

本诊断使用：

- `migration/datasets/batch_01..20`；
- 每批 `reference_measurements.csv` 前 84 条作为拟合集；
- 每批 `acceptance_tests.csv` 200 条作为独立评估集；
- 未使用验收标签拟合任何参数；
- 低保真输出由当前闭式模型在 `k_nominal = 25` 下计算；
- 每批独立估计对齐系数，对应单批材料建模口径。

前 84 条来自当前 `n_labeled = 120`、`train_fraction = 0.7` 的训练规模。当前正式
PWL还使用剩余 36 条进行超参数选择，且 `refit_on_train_validation = false`。

### 3.2 诊断模型

依次比较：

```math
M0: y_hat = y_LF,
```

```math
M1: y_hat = a + b y_LF,
```

```math
M2: y_hat = a + b y_LF + c P^{-0.7},
```

```math
M3: y_hat = a + b y_LF
    + c_1 q_int P^{-0.7}
    + c_2 q_int/(1+hL/k_nom) P^{-0.7}.
```

`M3` 的两列与当前 `heat_v3_qint` 中的两列核心机理特征一致，但该诊断是普通
最小二乘回归，不包含 PWL 的弱监督目标、稀疏组正则、BCD 或超参数选择。

### 3.3 结果

| 诊断模型 | 20 批平均 RMSE（K） | 相对上一臂变化 | 主要解释 |
|---|---:|---:|---|
| M0：identity | 15.276 | — | 原始低保真直接输出 |
| M1：仿射对齐 | 8.026 | -7.249 | 全局比例与偏移是主要误差源之一 |
| M2：加入 `P^(-0.7)` | 6.214 | -1.812 | 压强通道不能由一维 `phi` 表达 |
| M3：加入 `q_int` 机理项 | 4.763 | -1.451 | 界面温跃需要“热流 × 接触热阻”结构 |

M1 的 20 批平均绝对温度关系约为：

```math
y_HF \approx -447.9 + 2.526 y_LF.
```

由于输出包含约 293 K 的共同温度基线，绝对温度截距不便解释。以
`T0 = 293.15 K` 为基准改写为温升：

```math
Delta T = y - T0,
```

得到近似：

```math
Delta T_HF \approx -0.6 + 2.53 Delta T_LF.
```

该关系说明，高保真界面平均温升在当前输入域内约为低保真温升的 2.5 倍；主要
物理原因是高保真模型额外包含接触热阻与温度相关导热率。

### 3.4 诊断边界

上述结果用于判断“是否存在对齐通道”，不属于正式模型排名，原因包括：

1. 尚未按 10、20、…、120 标签档完整运行；
2. 尚未执行与 PWL 相同的验证选择和候选有效性检查；
3. 尚未进行重复划分或置信区间评估；
4. M3 的机理特征已经利用当前场景归因知识，必须作为明确的物理基线报告；
5. 诊断使用固定 `k_nominal`，而正式 PWL 的 `linear mapping` 会在校准后的
   当前 `theta` 上拟合 `phi`，两者不能直接等同。

因此，`4.763 K` 是需要正式复核的重要信号，而不是已经冻结的新冠军结果。

## 4. 对当前误差的统一解释

当前 PhysicsDirect 的约 15.3 K RMSE 不应整体归因于“相关性不足”。更合理的
误差结构为：

```math
Error_total
= Error_alignment
+ Error_conditional_discrepancy
+ Error_estimation
+ Error_noise.
```

其中：

- `Error_alignment`：温升尺度和整体偏移，M1 可显著降低；
- `Error_conditional_discrepancy`：接触热阻随 `P` 变化，以及顶面对流对界面热流
  的反馈，必须由 `B` 或机理修正处理；
- `Error_estimation`：标签有限、正则收缩和选参方差；
- `Error_noise`：验收标签固有噪声，RMSE 下限约为 `sigma = 4.494 K`。

RMSE 不能直接做线性减法，但从诊断路径可以确认：全局对齐解释了主要误差的一部分，
条件机理项又解释了剩余可约误差的大部分。

## 5. 对 PWL 适用性的影响

本诊断不支持“当前场景不适合 PWL”的简单结论，而支持更精确的条件判断。

### 5.1 适合的部分

- 低保真模型包含稳定的主要传热趋势；
- 弱标签生成成本低且输入覆盖充分；
- 主要结构偏差依赖可观测变量 `P/Q/h/T_inf`；
- v3 机理列能够表达主要接触热阻方向；
- 无弱标签消融表明物理蒸馏对小样本端有实际贡献。

### 5.2 不应声称的部分

- 不能以全局相关性高作为充分适用性证据；
- 不能声称 identity 映射已经是最佳输出对齐方式；
- 不能声称 PWL 自动发现了界面机理，当前成功依赖场景化 `B` 设计；
- 不能把 `theta` 解释为可恢复的真实材料导热系数；
- 在加入“对齐 + 机理修正”强基线前，不能声称 PWL 相对所有合理方法最优。

### 5.3 当前定位

当前场景对“少标签温度预测”属于**有条件适用**：

```text
物理趋势有用 + 偏差可观测 + 机理列可表达 => PWL 可用
```

但它不是“只凭高相关性即可直接套用 PWL”的场景。模型输出对齐和差异基函数设计
都是迁移过程的一部分。

## 6. 推荐正式实验协议

不得修改冻结配置 `heat_v3_qint_min.yaml` 或覆盖既有结果。应新建配置与结果目录，
至少设置以下实验臂：

| 实验臂 | `phi` | `B` | 回答的问题 |
|---|---|---|---|
| A0：当前基线 | identity | v3 qint | 当前事实基线 |
| A1：显式线性对齐 | linear | v3 qint | `phi` 是否减少弱监督尺度冲突 |
| A2：仅对齐 | linear | 仅截距 | 单纯全局对齐能够解释多少收益 |
| A3：无机理列 | linear | no_qq | 对齐后两列 qint 是否仍必要 |
| A4：机理对齐回归 | 温升仿射 | 两列 qint | 足够强且透明的物理基线 |

### 6.1 防泄漏要求

1. `phi` 只能在当前标签档的训练折拟合；
2. 验证折只能用于超参数或模型选择；
3. `acceptance_tests.csv` 全程不可用于拟合、选参或决定映射形式；
4. 每个标签档、每个批次独立拟合，保持嵌套样本协议；
5. 对比必须使用相同批次、相同训练/验证划分和相同验收集。

### 6.2 数值稳定性建议

建议在实现与报告中使用温升中心化形式：

```math
phi(y_LF) = T0 + alpha + beta (y_LF - T0).
```

它与普通仿射映射预测等价，但比在约 300 K 的绝对温度上报告巨大截距更容易解释。
若修改核心代码，应同时验证：

- 与当前 `linear` 映射的预测等价性；
- `refresh_weak_labels` 下每轮映射是否固定或重新估计；
- `theta` 与 `phi` 是否产生新的不可识别性；
- 映射系数是否在批次和标签档之间稳定。

### 6.3 正式验收指标

至少报告：

- 12 个标签档、20 批的 RMSE/MSE；
- `phi` 的截距、斜率及批间分布；
- `PWL-linear` 相对 `PWL-identity` 的逐批配对差；
- A4 相对 PWL 的逐批配对差；
- 未校正与 Holm 校正后的显著性；
- 小样本端和大样本端分别比较；
- MSE 与噪声方差 `sigma^2` 的比值；
- 无弱标签、无 B、无 qint 三项机制消融。

## 7. 决策规则

正式实验完成后按以下规则定案：

1. 若 A1 稳定优于 A0，说明 identity 映射不是合理主配置，应新建线性对齐基线；
2. 若 A1 只改善小样本端，说明 `phi` 主要起弱标签校准和稳定作用；
3. 若 A3 明显差于 A1，说明即使完成全局对齐，条件界面机理仍不可省略；
4. 若 A4 稳定优于 PWL，应把结论改为“机理对齐回归更适合当前场景”，并分析
   PWL 正则与模型类为何造成额外误差；
5. 若 PWL 在小样本端优于 A4、而大样本端被 A4 追平或反超，应将 PWL 的核心价值
   定位为标签效率，而非全样本规模下的绝对最优；
6. 只有在完整强基线集合和多重检验下通过，才能升级为“PWL具有统计优势”。

## 8. 推荐对外表述

> 当前热传导场景的高、低保真模型预测同一界面平均温度，但由于低保真模型忽略
> 接触热阻和温度相关导热率，二者之间同时存在全局尺度偏差与输入相关结构偏差。
> 20 批初步诊断表明，仿射输出对齐可将低保真直接预测 RMSE 从约 15.3 K 降至
> 约 8.0 K；进一步加入压强与界面热流机理项后可降至约 4.8 K，接近 4.49 K
> 的测量噪声下限。因此，全局相关性或恒等映射不足以描述物理模型的可用性。
> 合理的 PWL 实例化应由 `phi` 负责输出尺度对齐，由 `B` 负责可观测的条件结构
> 偏差，并通过对齐消融、差异项消融和强机理基线共同验证。上述 4.8 K 结果目前
> 属于诊断证据，尚需纳入冻结协议正式复核。
