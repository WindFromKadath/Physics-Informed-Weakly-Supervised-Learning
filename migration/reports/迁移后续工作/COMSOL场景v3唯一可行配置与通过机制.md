## 1. 唯一可行配置（逐项锁定）

当前唯一通过锚点 6 的配置 = `heat_v3_qint` 特征变体 + refresh 弱标签 +
`selection_rule: minimum`。其余模型参数沿用 refresh 主配置不变：

| 项 | 取值 | 实现原因 |
|---|---|---|
| B 库 | no_qq 6 列 + `q_int·P^(−0.7)` + `q_int/(1+hL/k_nom)·P^(−0.7)` | 见 §2.1 |
| q_int 计算点 | `k = k_nominal = 25`（常数） | 见 §2.2 |
| H 库 | 11 列不变（4 组，θ=1/k 仿射精确） | θ 不进标签拟合张成（秩 7），改 H 无收益 |
| 弱标签 | refresh 模式（θ 每轮 BCD 刷新，Case-B authentic） | W10 已确立的主配置；@10 优势来源 |
| 选参规则 | **`minimum`（验证集最小 MSE）** | 见 §2.3——通过与否的开关 |
| lambda 网格 | physics [0.01,0.1,1,10] × l1/group [0.001,0.01,0.1] | 与历史臂可比；minimum 下低端网格被真正使用 |
| d_ridge / ADMM / BCD | 10.0 / max_iter 20000 / max_iter 80 | refresh 模式下收敛率 1.0 所需的既有工程设定 |

## 2. 每个决策的实现原因（与被否决的替代方案）

### 2.1 为什么恰好是这两列 B

真模型的接触项为 `q_int^HF(Q,h,T_inf,P)·P^(−0.7)`，其中高保真通量因顶 BC
反馈携带 P 依赖极点结构 `1/(1+hLθ+hR₀·s)²`（s=P^(−0.7)）。逐候选方案的
无噪声类偏置（δ²，20k LHS 投影，越小越好）：

| 候选 B 列（在 no_qq 6 列上追加） | δ² (K²) | 判定 |
|---|---:|---|
| 不加（v2 现状） | 7.2 | 缺口所在 |
| W4 式精确幂次插值（P^(−0.7)、q_int·P^(−1.4) 等） | ≥4.2 | ❌ 不对症：缺口在 h 调制而非 P 幂次 |
| 单列 `q_int·P^(−0.7)`（任何 k） | 4.5–5.4 | ❌ 不足：q_int^LF 不含反馈极点结构 |
| 单列 `q_int/(1+hL/k)·P^(−0.7)` | 1.7 | ❌ 不足 |
| HF 精确通量列 `q_int^HF·P^(−0.7)` | 0.15 | ❌ 工程不可用：需逐点解高保真 BVP，违背"弱标签免费"前提 |
| **两列 `q_int·s` + `q_int/(1+hL/k)·s`** | **0.44** | ✅ **唯一同时满足"低保真免费 + 类偏置压平"的方案** |

第二列的 `1/(1+hL/k)` 恰好是反馈极点对 s 的一阶（Taylor）结构——这是
两列组合有效的数学原因，不是试出来的巧合。

### 2.2 为什么 q_int 用 k_nominal 而不是 k_true 或 θ̂

- **k_true**：实验上不可得（它就是被估计的对象），且与"实践中只有标称值"
  的场景设定矛盾；
- **θ̂（当前值）**：会把 θ 的估计噪声注入 B 列，且 θ̂ 高撞界率（0.5–0.6）使
  该列在多批退化为边界常数的倍数；实测 k_nominal 与 k_true 的 δ² 差异
  （5.4 vs 4.5 单列口径）在两列组合下已被抹平（0.44）；
- **k_nominal**：与弱标签生成口径一致，列只依赖 (Q,h,T_inf,P)，
  与 `heat_b_raw(x_ph, x_pr)` 签名兼容，零侵入。

### 2.3 为什么必须换 minimum 选参（通过的真正开关）

1-SE 规则 `λ̂ = max{λ : MSE_val(λ) ≤ min + SE}` 在本场景结构性失效：
n_val=36 时 SE ≈ σ²·√(2/36) ≈ 4.8 K²，而相邻 λ 臂的验证 MSE 差仅 1–2 K²
≪ SE ⇒ 选择集恒含最强物理权重 ⇒ **λ_physics=10 不随 n 衰减**（v3 1-SE 臂
@120 仍 9/10 批选 10）。强物理锚把 d 拉向弱标签拟合，产生常驻正则平移
b²——它不光独立存在，还**吸收 B 修复的红利**（1-SE 臂修复仅兑现 1.9 K²，
预测上限 6.8 K²）。

改为 minimum 后 λ_physics 自然散落（@120：7/10 批 ≤0.1），@120 MSE 再降
2.68 K²。网格扩低端等其他手段对 1-SE 无效（选择集仍含最强权重），
**换规则是唯一通道**。

### 2.4 为什么保留 no_qq 基座（B 不含 Q/Q² 列）

W1 已证：B 的 Q/Q² 列与 H 的 θ 组 `θ·[1,Q,Q²,Q/h]` 张成同一空间，d 会吸收
k 校准偏差使 θ 沿惩罚梯度滑向边界。no_qq 是 θ 行为可控（撞界率 0.5–0.6
vs 首版 0.9）的前提。

## 3. 为什么现在能通过：完整因果链

@120 超额误差（MSE − σ²，σ²=20.2）的逐臂分解：

```
refresh 基线   超额 13.25 = δ²(7.2)  + b²+est(6.0)
v3 (1-SE)      超额 11.33 = δ²(≈0.4~2)+ b²+est(≈10)   ← B 修复被强 λ 吸收大半
v3 (minimum)   超额  8.65 = δ²(≈0.4) + b²(≈1~2) + est(≈3) + 收缩偏置(≈4)
```

三条机制共同作用，缺一不可：

1. **类偏置通道（两列 B）**：模型类地板从 δ²=7.2 压到 ≈0.44 K²——PWL 的
   参数类极限首次低于 GP 在 n=120 的估计误差，交叉点被推出实验范围。
   直接证据：10/10 批 top-3 |d| 稳定含 col7（q_int/(1+hL/k)·P^(−0.7)）。
2. **协议通道（minimum 选参）**：λ_physics 从恒 10 散至 0.01–1.0，正则
   平移 b² 从 ~6 K² 量级降到 1–2 K²，回收 2.68 K²。**单独做 B 修复
   （1-SE 臂）差距只从 0.254 收到 0.077，不翻盘；两条都做才通过**——
   这正是归因 v2"基函数与协议各占一半"预测的实验兑现。
3. **小样本端未受损**：refresh 弱标签的蒸馏正则化保持，gap@10 从 1.54
   扩大到 2.00（PWL@10 = 8.06 全面最优）；PWL 自 n=90 起全部最优，
   MSE/σ²=1.43 为迄今最接近噪声下限的一次。

对照基线（@120，10 批均值 RMSE）：PWL **5.366** < Physics-GP 5.530 <
GP 5.673 < 最优纯参数基线 6.330 ≪ PhysicsDirect 15.668。

## 4. 边界与脆弱点（通过不等于收敛到极限）

- **残余 ~5 K² 未分解**：minimum 臂超额 8.65 中，δ² 0.44 + est ~3 之外仍有
  ~5 K² 来自 λ_l1/λ_group 收缩偏置与 n_val=36 的选参噪声——这是下一个
  优化靶点（λ 网格细化、重复划分验证、refit 合并）；
- **θ 依旧不可识别**：撞界率 0.6（warn）、学习分数 0.3（fail）。属物理
  结构固有（k 与 R_c 串联、等效 k≈2–3 在盒外、rank(H)=7），minimum 下
  λ 减小使 θ 约束更弱，数值略恶化但不影响精度结论；
- **minimum 规则的推广边界已定案（P3，2026-08-03）**：本场景弱标签偏差温和，
  minimum 选择小 λ 恰好正确；在 IV-B 三档物理精度（弱标签偏差加大）下，
  minimum 可能过信标签放弃物理锚——经仿真线对照实验，**minimum 定位为
  场景相关规则，不全局推广**：仿真线保持 1-SE，热传导保持 minimum
  （`reproduction/reports/选参规则跨场景对照报告.md`）；`heat_refresh.yaml`
  等历史配置保持 1-SE 口径，跨臂比较时注意；
- **双保真相关性锚点仍 fail**（批次 6 = 0.691 贴界）：数据属性，与模型无关；
- 无效候选率 0.2435 贴 0.25 上限：refresh 模式固有，扩网格/批次时留意。

## 5. 一句话总结

> **唯一可行路径 = "两列低保真免费机理列把类偏置地板从 7.2 压到 0.44"
> 加上 "minimum 选参解开 1-SE 钉死的 λ_physics=10"；前者修好模型类，
> 后者让训练真的逼近修好的类极限——两条通道各占一半，只做任何一条
> 都无法让 PWL @120 反超 Physics-GP。**
