## 1. 协议与实验臂

### 1.1 实验臂定义（§6 协议表）

| 臂 | 实现 | 配置/代码 |
|---|---|---|
| A0 | 冻结 b20 结果同批子集（identity + heat_v3_qint） | `heat_v3_qint_min_b20`（只读） |
| A1 | `mapping: linear` + `heat_v3_qint` | `heat_a1_linear_qint_b20.yaml` |
| A2 | `mapping: linear` + `heat_no_b`（仅截距） | `heat_a2_linear_no_b_b20.yaml` |
| A3 | `mapping: linear` + `heat_no_qq` | `heat_a3_linear_no_qq_b20.yaml` |
| A4 | 温升仿射 + 两列 qint，训练折普通最小二乘 | `heat_experiments.py::_mechanism_aligned_condition` |

A1–A3 与冻结 A0 仅 `model.mapping` / `model.feature_spec` 两项差异，种子、
嵌套划分、验收集、lambda 网格、求解器参数逐项一致，保证逐批配对有效。
A4 作为 `MechanismAligned` 场景基线随三臂同运行（三份逐值相同，取 A1 目录
副本），定义为

```text
y - T0 = alpha + beta*(y_LF - T0) + c1*q_int*P^-0.7
         + c2*q_int/(1 + hL/k_nom)*P^-0.7
```

其中 y_LF、q_int 均由 k_nominal = 25 的低保真闭式解计算；无超参数、无弱
标签、无迭代求解。

### 1.2 各臂的"对齐方案"

统一结构（上游诊断 §0）：低保真输出先由 phi 做全局尺度对齐，再由 B 对
随过程变量（P/Q/h/T_inf）变化的条件结构偏差做补偿：

```text
低保真输出 y_LF --phi：全局尺度对齐--> 已对齐物理趋势
                                          +
过程变量 x=(Q,h,T_inf,P) --B：条件偏差补偿--> 真实系统预测 y_hat
```

五个臂即 phi 与 B 两个自由度上的不同取值：

- **A0（恒等对齐 + 全量差异补偿，当前基线）**：phi(y_LF) = y_LF，不做
  任何显式校准；尺度/偏移误差由 H 的截距与系数、B 的 8 列差异项在
  PWL 训练目标内隐式吸收；弱标签随 refresh_weak_labels 在当前 theta
  处刷新。
- **A1（显式线性对齐 + 全量差异补偿）**：phi(y_LF) = a + b*y_LF，a/b
  仅在训练折上于校准 theta 处 OLS 拟合，拟合一次后在 BCD 全程固定；
  弱标签先经 phi 再进入蒸馏项；B 为 v3 qint 8 列（含两列机理项）。
  意图：phi 先消除低阶尺度差，使 B 集中描述输入相关偏差。
- **A2（仅对齐，无差异补偿）**：phi 同 A1，B 退化为仅截距列（仅能
  吸收常数偏移）。意图：隔离"单纯全局对齐"的解释力。
- **A3（线性对齐 + 无机理列差异补偿）**：phi 同 A1，B 为 no_qq 6 列
  （去掉 q_int 两列机理项）。意图：检验对齐完成后机理列是否仍必要。
- **A4（机理对齐回归，透明强基线，非 PWL）**：温升仿射 phi 与两列
  q_int 机理修正显式并联，4 个系数在训练折上一次 OLS 解析求解；无
  弱标签、无稀疏/组正则、无迭代。意图：给出"对齐 + 机理修正"结构的
  无正则对照上限，检验 PWL 的正则与模型类是否自带额外误差。

### 1.3 防泄漏落实（§6.1 逐条）

1. A1–A3 的 phi 由 `PWLRegressor._fit_mapping` 在传入 `fit` 的训练折上
   OLS 拟合，验证折与验收集不参与（测试
   `test_linear_mapping_phi_uses_train_fold_only` 锁定）；
2. 验证折仅用于 lambda 网格选择（与 A0 同协议）；
3. `acceptance_tests.csv` 全程只读评估（A4 有专门的投毒测试
   `test_mechanism_aligned_fit_ignores_eval_data` 锁定）；
4. 每标签档、每批次独立拟合，嵌套样本协议与 A0 逐种子一致；
5. 全部对比使用同批、同划分、同验收集；A0 数值取冻结 b20 结果的
   批次 1–5 子集（故 A0 @120 = 5.410，区别于 20 批口径的 5.351）。

### 1.4 小范围口径说明

批次 1–5（配对 n=5）功效有限，尤其小样本端置信区间很宽；本报告全部
p 值仅作方向参考。20 批正式协议配置已就绪
（`uv run python migration/run_migration.py --config <臂yaml>`）。

## 6. §7 决策规则逐条判定

1. **R1（A1 稳定优于 A0 → identity 不是合理主配置）：不成立。**
   A1−A0 @120 = +0.140 K（p=0.877），12 档中 9 档为正。identity 映射
   可以保留；线性 phi 对完整 PWL 无收益；
2. **R2（A1 只改善小样本端）：不成立。** 小端 −0.003 K（p=0.495），
   大端 +0.103 K（p=0.918），两端均无改善；
3. **R3（A3 明显差于 A1 → 对齐后 qint 仍必要）：成立（方向性）。**
   A1−A3 @120 = −0.139 K（p=0.0089，5/5 批）；机理列价值与是否对齐
   无关；
4. **R4（A4 稳定优于 PWL → 结论改为机理对齐回归更适合）：触发
   （方向性，强）。** A4−A0 @120 = −0.621 K（Holm p=0.0008，5/5 批，
   12/12 档均值全胜）；对 A1 同向（−0.761 K，Holm p=0.0092）。
   机制分析：A4 以 4 列精确机理结构（温升仿射 + 热流×接触热阻两个
   方向）直接估计，系数少而稳定；PWL 则把同一效应分摊到 11 列 H 与
   8 列 B 上，并承受三重收缩（L1、组 Lasso、d_ridge=10）与蒸馏锚定
   ——即便 phi 消除了全局尺度差，随 P/Q/h/T_inf 变化的条件偏差仍须
   由被收缩的 B 列拟合，偏差-方差权衡在小标签量下系统劣于直接 OLS；
5. **R5（PWL 小端优、大端被追平 → 价值定位为标签效率）：不成立。**
   A4 在小端（−0.898 K）与大端（−0.725 K）均占优；@10 档 A4 高方差
   是唯一例外，但 5 批证据不足以支持"PWL 小样本端更稳"的反向结论；
6. **R6（完整强基线 + 多重检验通过才可称 PWL 统计优势）：不满足。**
   A0 相对既有最强基线 Physics-GP 的 20 批优势本就未过 Holm 门
   （p=0.0708），本次又新增稳定更强的 A4 基线。

## 7. 结论与后续

小范围口径的结论：**当前热传导场景上，"温升仿射 + 两列 qint"的透明
机理对齐回归（A4）是更强基线并稳定优于 PWL 各臂；PWL 的显式线性 phi
（A1）无收益，而 qint 机理列（A3 对照）与差异补偿通道（A2 对照）均
不可省略。** 按 §7 规则 4，主结论应改写为"机理对齐回归更适合当前
场景"，PWL 的价值主张需重新定位（例如不限于本场景机理可精确表达的
情形）。
