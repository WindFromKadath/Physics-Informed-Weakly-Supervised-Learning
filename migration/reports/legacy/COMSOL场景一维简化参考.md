## 1. 核心结论

> **当前三维场景在物理上严格等价于一维，约化是无损的（非近似）。验证/测试床阶段应采用一维模型，COMSOL 三维求解非必需。**

- 约化终点是 **1D 而非 2D**：立方体不具轴对称性，2D 轴对称不适用；取 x-z 剖面做 2D 平面，因无 x 方向变化仍退化为 1D。
- 一维模型存在**完整闭式解析解**（恒定 k 情形），低保真模型可直接取该闭式解，高保真模型为一维非线性边值问题（毫秒级数值求解）。
- 设计的全部核心性质（方差份额结构、三难权衡、双保真偏差、四集设计）均为一维热阻网络的性质，**与空间维度无关，全部保留**。
- 计算成本下降约 **1000×**：高保真单次求解从 10–60 s 降至毫秒级，整套数据生成从小时级降至秒级，参数扫描可即时穷举。

## 2. 对称性论证：为什么是 1D

温度场 `T(x, y, z)` 退化为 `T(z)` 的充分条件是场景对 x、y 方向完全对称。逐项核对主规格 v1.2 的设置：

| 要素 | 设置 | 破坏 x-y 对称？ |
|---|---|---|
| 几何 | 立方体 `[0, L]³` | 否 |
| 热源 | 均匀体积热源 Q | 否 |
| 底面 z=0 | 均匀恒温 T0 | 否 |
| 顶面 z=L | 均匀对流 h、T_inf | 否 |
| 侧面 | 绝热（对任意 T(z) 自动满足） | 否 |
| 界面 z=L/2 | 均匀接触热阻 R_c(P) | 否 |
| 材料 | k(T)，仅依赖温度 | 否 |

由稳态热方程解的唯一性，温度场必为 `T = T(z)`。侧面绝热 + 顶底均匀边界不存在任何驱动横向变化的源项，**边角效应亦不存在**。

两条旁证表明这并非新发现，而是设计本就如此：

1. 主规格 §3 的解析验证基准即"**分段一维热传导**"——三维 COMSOL 只是数值重解一个一维问题；
2. 定案所用的 4096 样本参数扫描使用解析（一维）模型，COMSOL 仅做实测互证——**三维从未贡献新物理，只贡献计算成本**。

## 3. 一维模型数学表述

### 3.1 几何与控制方程

一维域 `z ∈ [0, L]`，`L = 0.1 m`；界面位于 `z = L/2`。下层 `z ∈ [0, L/2]`，上层 `z ∈ [L/2, L]`。稳态、均匀内热源：

```text
k · d²T/dz² + Q = 0      （各层内，恒定 k 情形）
```

温度场为分段二次函数：

```text
T1(z) = −Q/(2k)·z² + a·z + b      z ∈ [0, L/2]   （下层）
T2(z) = −Q/(2k)·z² + a·z + d      z ∈ [L/2, L]   （上层）
```

（两层材料相同，故二次项与一次项系数相同；界面条件仅决定常数项跃变。）

### 3.2 边界与界面条件

```text
底面：  T1(0) = T0 = 293.15 K
顶面：  −k·dT2/dz|_{z=L} = h·(T2(L) − T_inf)
界面热流连续：  −k·dT1/dz|_{L/2} = −k·dT2/dz|_{L/2} = q_int
界面温跃：  T1(L/2) − T2(L/2) = R_c · q_int      （高保真；低保真 R_c = 0 无跃变）
```

热流向上为正：`q(z) = −k·dT/dz = Q·z − k·a`，故界面热流 `q_int = Q·L/2 − k·a`。

### 3.3 输出定义（界面温跃的处理）

高保真模型中界面存在温跃 `ΔT_int = R_c·q_int`，"界面温度"有两侧之分。为保证高/低保真输出在同一物理位置可比：

> **输出 y 定义（v1.1 修正，与已生成数据一致）：界面两侧平均温度 `y = (T1+T2)/2 = T1(L/2) − ΔT_int/2`。** 本文初版曾取界面下侧温度 `T1(L/2)`；数据落地时改为两侧平均以对称处理温跃（见 `datasets/README.md` §2 与批次 metadata 的 `output_definition`）。低保真模型 R_c = 0 时 `T1(L/2) = T2(L/2)`，两种定义一致，故 §3.4 闭式解作为低保真模型不受定义差异影响。温跃 `ΔT_int` 作为派生量记录，可用于 P 通道机理诊断。

### 3.4 闭式解析解（恒定 k，含 R_c）

记单位面积热阻：`R_lower = L/(2k)`、`R_upper = L/(2k)`、`R_conv = 1/h`。一次项系数 a 由顶面对流边界唯一确定：

```text
        Q·L·(R_lower + R_c/2 + R_conv) + (T_inf − T0)
a  =  ─────────────────────────────────────────────────
              L + k·(R_c + R_conv)
```

由此得全部待求量：

```text
界面热流：   q_int = Q·L/2 − k·a
输出温度：   y = T1(L/2) = T0 − Q·L²/(8k) + a·L/2
上层常数：   d = T0 − R_c·q_int
界面温跃：   ΔT_int = R_c · q_int
```

**校验**：令 `R_c = 0`（完美界面），上式退化为单层平板（底面恒温 + 顶面对流 + 均匀内热源）的标准解，可与传热学教材对拍。该闭式解即主规格 §3 的解析验证基准，在一维下成为**主模型本身**。

### 3.5 热阻网络解释

界面下侧温度 y 可理解为：底面恒温锚定 T0，内热源经下/上两条通路分流——向下经 `R_lower` 汇入 T0 热沉，向上经 `R_c + R_upper + R_conv` 汇入 T_inf 环境。P 通道的杠杆来自界面热流 `q_int` 流过 `R_c(P)` 产生的温跃；**q_int 的大小由分流结构决定**，这正是决策记录 §8.2 三难权衡（P 需不对称分流）在一维下的精确表述。

## 4. 双保真模型在一维下的具体形式

### 4.1 高保真参考模型（生成 y / 测试集）

```text
材料：    k(T) = k_true · (1 + 0.002·(T − 300))，k_true ~ U[15, 35]（逐批）
界面：    R_c(P) = R0 · P^(−0.7)，R0 = 3e-2 m²K/W
求解：    一维非线性边值问题（k 依赖 T），打靶法或一维网格 Newton，毫秒级
```

k(T) 引入非线性，无简单闭式解，但一维非线性 BVP 数值求解极快。

### 4.2 低保真工程模型（生成弱标签）

```text
材料：    k = k_nominal = 25 W/(m·K)（恒定，标称值）
界面：    完美贴合，R_c = 0
求解：    §3.4 闭式解直接代入（R_c = 0，k = 25），无需数值求解
```

低保真模型退化为**一次函数求值**，批量生成 N ≫ n 个弱标签的成本可忽略。

### 4.3 差异来源清单（一维下）

| 差异项 | 高保真 | 低保真 | 性质 |
|---|---|---|---|
| 材料非线性 | k(T) 温度依赖 | 恒定 k | 结构性，随温升放大 |
| 界面 | R_c(P) 接触热阻 | 无（完美贴合） | 结构性，**P 通道载体** |
| 材料参数 | k_true（逐批真值） | k_nominal = 25 | 参数性，批次间波动 |
| 网格 | （一维下可忽略） | （一维下可忽略） | 次要差异，**一维下退出** |

一维下双保真偏差**完全来自物理简化**，不被数值/网格误差污染——对"研究模型差异"的测试床而言是更可控的实验条件。

## 6. 对原设计的影响

### 6.1 完全保留

以下性质均为一维热阻网络的性质，与维度无关，参数扫描已在一维下验证：

- 四通道方差份额（Q 62.9% / h 3.6% / T_inf 3.6% / P 18.7%，合计 88.7%）与三难权衡结构；
- 双保真偏差结构与高低保真相关性（预估 0.89）；
- 四集设计（参考测量 120 / 工程预测 100–500 / 独立验收 200 / 标定集）、嵌套结构、批次结构；
- SNR=5 噪声注入、σ 的"综合重复性误差"定义；
- 全部验收标准（主规格 §5）。

### 6.2 弱化或退化

| 项 | 变化 | 影响 |
|---|---|---|
| 网格粗细差异源 | 一维网格求解近乎精确，差异可忽略 | 无实质影响——设计本就标注为"次要差异"，主差异来自物理简化 |
| "界面中心点温度" | 退化为"界面温度"（整面等温） | 输出物理量不变，仅不再有空间选点问题；按 §3.3 取下侧温度 |
| COMSOL 三维建模 | 不再必需 | 解析解 + 轻量数值求解即可覆盖双保真两档 |

### 6.3 更干净之处

- 双保真偏差来源完全可解析归因（k(T)、R_c、k_nominal 三项），便于机理诊断与消融；
- 低保真闭式解使弱标签生成零成本，"N ≫ n"的成本不对称成为纯粹的设计选择而非计算约束；
- 解析解作为主模型，验证锚点（主规格 §3）从"对拍基准"升格为"模型本身"，建模正确性风险大幅降低。

## 8. 实施建议

1. **验证/测试床阶段采用一维**：以 §3.4 闭式解为低保真模型、一维非线性 BVP 数值解为高保真模型，无需 COMSOL；
2. **先验证闭式解**：用 R_c = 0 单层极限与传热学标准解对拍，再验证含 R_c 的双层解（能量守恒：`q(0)` 与 `q(L)` 之差等于总发热 `Q·L`）；
3. **高保真数值解收敛性**：一维网格 10³ 节点量级即可，Newton 迭代收敛判据 1e-10；
4. **采样管线不变**：仍按主规格 §4 的 LHS + 批次结构生成四集，仅把"调用 COMSOL"替换为"调用一维求解器"；
5. **与论文的关系**：一维热传导测试床比原 PWL 论文式 (9)–(11) 的玩具函数更具物理结构，作为合成基准完全够格，不存在"过于简化"的效度风险。

## 9. 三维扩展的保留条件

一维是当前对称设置的精确约化。若后续研究需要真实三维效应或空间分辨输出，必须**主动打破对称性**，否则三维仍退化为一维。可选的对称性破缺手段：

| 手段 | 引入的效应 | 所需维度 |
|---|---|---|
| 偏心/局部热源 | 横向温度梯度 | 2D 或 3D |
| 空间非均匀接触热阻 R_c(x,y) | 界面热流横向再分布 | 3D |
| 局部边界条件（点冷却/局部对流） | 三维热流路径 | 3D |
| 非均匀/各向异性材料 | 横向导热差异 | 2D 或 3D |
| 圆柱几何 + 轴对称载荷 | 径向效应 | 2D 轴对称 |

此时"点温度"输出重新获得空间意义，需相应升维建模。建议将"对称性破缺的三维扩展"作为**可选后续阶段**，而非当前测试床的负担。

## 11. 一句话总结

> **当前三维场景因全 x-y 对称而严格等价于一维；采用一维闭式解（低保真）+ 一维非线性 BVP（高保真）可在无损保留全部设计性质的前提下获得约 1000× 加速，COMSOL 三维求解仅在后续主动打破对称性时才重新需要。**
