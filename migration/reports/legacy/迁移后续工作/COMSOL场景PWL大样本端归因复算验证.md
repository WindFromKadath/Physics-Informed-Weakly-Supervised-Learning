## 1. 验证基础：数据生成过程精确在手（报告的扎实部分）

自建高保真求解器：Kirchhoff 变换 u(T) = k_true·[(T−300) + (β/2)(T−300)²]，
两层 u(z) = −Qz²/2 + a·z + d_i，界面温跃 T1−T2 = R_c(P)·q_int（符号由数据
`dT_int` 列锁定，与《一维简化参考》§3.2 一致），顶 BC QL−a = h(T(L)−T_inf)，
二维向量化 Newton（~5 次迭代，max|F| ~ 1e-13）。三项独立校验：

| 校验 | 结果 |
|---|---|
| β=0、R0=0 极限 vs 低保真闭式 | max\|err\| = 5.684e-14 K ✅ |
| 低保真闭式 vs `engineering_predictions.csv`（10 批） | max\|err\| = 5.684e-14 K（报告 5.7e-14 ✅） |
| 高保真 vs batch_01 `y_obs`（k_true=18.2391） | MSE = 21.7360（σ²=20.195，n=120 采样 std≈2.61 ✅）；解出温跃 vs `dT_int` 列 max\|err\|=1.7e-11 |
| 10 批池化（n=1200） | MSE=20.90，残差 std 4.57≈σ ✅ |

另：分解网格 Var(y_HF) = 138.8–140.3（3 种子），与报告 139.2 一致——
**y_HF 分布完全相同，分歧只出在投影口径**。

## 2. 核心问题：§4.2 分解数字在自述口径下复现不了

20k LHS（Q∈[1e4,1e5]，h∈[3,50]，T_inf∈[273,323]，P∈[0.5,10]，k=18.2391，
列归一化 lstsq，SVD 交叉验证一致，3 种子波动 <6%）：

| 项 | 报告值 | 复算值 | 判定 |
|---|---:|---:|---|
| A：H 对低保真 | 1.012 | 0.103–0.104 | ❌ 所有自洽配置均复现不了 |
| B：H 对高保真 | 39.545 | 33.94–35.37 | ❌ |
| C：[H, B_v2] 类偏置 δ² | 12.249 | **6.900–7.323** | ❌ ~1.7× |
| D：+ [P^(−0.7), q_int·P^(−0.7)]（q_int 低保真 @k_true） | 0.331 | **4.458–4.516** | ❌ ~13× |
| D 同左（q_int 低保真 @k_nominal=25） | 0.331 | **5.293–5.419** | ❌ ~16× |

### 2.1 反向工程：报告数字需要什么配置才能出现

| 配置 | 残差 MSE (K²) |
|---|---:|
| C 复现：B 删去 Q/P、Q·P^(−1/2) 两列（4 列 B） | 11.65–11.98 ≈ 报告 12.25 |
| D 复现：q_int 用**精确高保真界面通量**（需求解 HF BVP） | 4 列 B 版 0.315–0.319；6 列 B 版 0.150 |
| 报告口径（6 列 B_v2 + 低保真免费 q_int） | 4.5–5.4（见上表） |

即 **12.25 与 0.33 需要互相矛盾的配置分别逼近，不是同一口径的产物**。
0.33 所要求的 HF 精确通量违背报告自己"从低保真闭式免费逐点计算"的工程前提。

### 2.2 物理根源

β=0 时接触+反馈项有精确结构（推导见验证脚本 docstring）：

```
Δy = (R0/2)·s·M0·[hL(1−θ)−1] / (1 + hLθ + hR0·s)²,   s = P^(−0.7), M0 = h(T0−T_inf) − QL/2
```

顶 BC 通量反馈引入 **P 依赖的极点结构** `1/(1+hLθ+hR0·s)²`，而低保真
`q_int = M0/(1+hLθ)` 不含此结构——故 q_int 的任何倍数都无法严格表出，
单列低保真 q_int 只能到 4.5–5.4。这不是网格/单位/种子问题。

### 2.3 连带后果：§6 总账需重估

报告"PWL @120 超额 13.25 = δ²(12.25) + est(≈1)"不成立。按实测 δ² ≈ 7：

```
超额 13.25 ≈ δ²(7) + [估计误差 + 正则平移](≈6)
```

**估计/协议项 ~6 K²**，远大于报告结论的 ~1。报告 §5 将协议项降级为
"二阶效应"的判定撤回过早——λ_physics 不松弛 / 1-SE 规则问题实际是
与基函数缺口**同等量级**的误差源。

## 3. 仍然成立的部分与新的可落地方案

- **定性方向正确**：复算确认 W4 式补精确幂次几乎无效（4.458→4.152，
  加 q_int·P^(−1.4) 列），而补机理列有效——"缺口在 h 调制而非 P 幂次"成立。
- **两列低保真免费修复**（复算新发现，脚本 §3b `D_2LFcols`）：

```
B 新增两列：  q_int·P^(−0.7),   q_int/(1+hL/k_nominal)·P^(−0.7)
```

第二列承载通量反馈/幅度调制的一阶结构。类偏置 → **0.372–0.381**，
达到报告 D 行量级，且两列都只依赖 (Q,h,T_inf) 与常数 k_nominal，
与现有 `heat_b_raw(x_ph, x_pr)` 签名兼容。
（对照：单列调制版 `q_int/(1+hL/k)·P^(−0.7)` → 1.71。）

## 4. 修正后的预期与实验建议

| 方案 | 类偏置 δ² (K²) | PWL @120 预期 MSE（est≈6 维持） | 对 Physics-GP（30.58） |
|---|---:|---:|---|
| 现状（refresh 主配置） | ~7 | 33.45（实测） | 落后 |
| 单列 q_int(k_nom)·P^(−0.7) | ~5.3 | ≈ 26–27（RMSE≈5.2） | 有望反超，优势 ~0.4 K |
| **两列版（推荐）** | **~0.37** | ≈ 26–27（受 est 主导） | 有望反超，优势受 est 限制 |

注意：两列版把类偏置压到 0.37 后，预期 MSE 由 ~6 K² 的估计/协议项主导，
与单列版拉不开差距——**协议项不处理，类偏置修复的红利只能兑现一部分**。

建议：

1. 实现 `heat_v3_qint` spec 变体（两列版），配置 `configs/heat_v3_qint.yaml`
   沿用 `heat_refresh.yaml`，跑 default 规模；
2. 验收标准修正为：**@120 档 PWL RMSE < Physics-GP（5.53）即锚点 6 通过**，
   而非报告的 MSE 22–23；@10 档优势不退化；
3. 协议项列为并行工作项：λ_physics 网格向低端扩展 / 1-SE 规则修订 /
   验证集口径复核，量化 ~6 K² 中估计误差与正则平移的占比；
4. θ 撞界率、无效候选率按首版口径同步监控（新列改变 d/θ 争抢结构）。
