## 0. 问题与结论摘要

**问题**：迁移实验中 PWL 在 120 标签档被 Physics-GP（5.53）与 GP（5.67）反超，
为何没有保持最优？该问题是否可归因到"基函数"？

**v2 结论**：可以归因到基函数，但**只占约一半**。PWL @120 超额误差 13.25 K² 的
分解为：

```
超额 13.25 K² ≈ δ²(≈7.2, 基函数缺口, ~54%) + [估计误差 + 正则平移](≈6, ~46%)
```

- **基函数缺口（结构性）**：真实接触项 = `q_int(Q,h,T_inf,P)·P^(−0.7)`，其中
  高保真 q_int 携带顶 BC 通量反馈引入的 **P 依赖极点结构**；B 库是
  {Q^a·P^b} 单项式库（对 h 依赖为零），无法表出。低保真免费的两列修复
  （§8）可把 δ² 压到 ~0.44 K²；
- **估计/协议项（~6 K²）**：λ_physics 在 1-SE 规则下不随样本量衰减
  （@120 仍 7/10 批选 10.0）引入常驻正则平移，叠加 ~13 个有效方向的
  估计误差（σ²·p/n ≈ 3 K²）。此项不处理，基函数修复的红利只能兑现一部分。

**可检验预测（修正）**：两列修复后 PWL @120 预期 MSE ≈ 26–27（RMSE ≈ 5.1–5.2），
有望反超 Physics-GP 的 30.58（RMSE 5.53）但非决定性；验收标准定为
**@120 RMSE < 5.53 即锚点 6 通过**。

## 3. 数学框架：超额风险分解

设 y = f(x) + ε，ε∼N(0, σ²)，σ²=20.2。任意学习器在样本量 n 下：

```
MSE(n) = σ²  +  δ²(类)  +  b²(λ,n)  +  est(n)
          噪声    逼近偏置    正则平移偏置    估计误差
```

- δ²(类) = dist(f, 𝒫)²：模型类 𝒫 = span(H(θ), B) 对 f 的不可约逼近误差，与 n 无关；
  **注意 H 取仓库真实 11 列（秩 7），这是 v2 与 v1 的分水岭**；
- b²(λ,n)：惩罚项把总体极小点从 β* 平移到 β∞(λ) 的偏置；
- est(n)：估计误差，随 n 衰减（~σ²·p_eff/n，p_eff≈13）。

## 4. 原因一（结构性）：乘积方向 q_int·P^(−0.7) 缺失——修正版

### 4.1 真模型的解析结构

稳态方程 −(kT′)′ = Q，两层同材料 ⇒ 各层通解 T(z) = −Qz²/(2k) + c·z + d。
顶面 BC 解出通量常数（低保真，R_c=0）：

```
a_LF = θ·[QL + (hL/2)·QLθ − h(T₀−T_inf)] / (1 + hLθ),      θ = 1/k
q_int^LF = QL/2 − k·a_LF = g(Q, h, T_inf; θ)     —— P 无关
```

**高保真中 R_c 通过界面温跃反馈改变温度剖面与分流**，顶 BC 使 q_int 获得
P 依赖的极点结构（复算文档 §2.2 给出 β=0 时的精确式：
分母含 (1 + hLθ + hR₀·P^(−0.7))² 型项）。因此：

```
q_int^HF = g(Q, h, T_inf; θ, P)     —— P 依赖！
f = Φ(Q,h,T_inf;θ) − (R₀/2)·q_int^HF(Q,h,T_inf,θ,P)·P^(−0.7) + O(β·ΔT²)
```

低保真 q_int^LF（P 无关）的**任何倍数都无法表出**该乘积结构——这是单列
修复只能到 4.5–5.5 的物理根源，不是网格/单位/种子问题。

### 4.2 无噪声精确分解（20k LHS，k=18.24；**真实 11 列 H + v2 6 列 B**）

| 步骤 | 内容 | 残差 MSE (K²)，3 种子 |
|---|---|---:|
| A | H 对低保真闭式（截断误差） | 0.102–0.106 |
| B | H 对高保真 | 34.49–34.88 |
| C | **[H, B_v2] 对高保真 = 参数类精确偏置 δ²** | **7.209–7.367** |
| D-HF | C + [P^(−0.7), q_int^HF·P^(−0.7)]（仅诊断，工程不可用） | 0.149–0.152 |
| D-LF@k_true | C + [P^(−0.7), q_int^LF(k_true)·P^(−0.7)] | 4.477–4.606 |
| D-LF@k_nom | C + [P^(−0.7), q_int^LF(k_nom=25)·P^(−0.7)] | 5.386–5.530 |
| **两列修复** | C + [P^(−0.7), q_int^LF·s, q_int^LF/(1+hL/k_nom)·s] | **0.435–0.458** |

k(T) 温度依赖独立核算（Kirchhoff 级数修正 (β/2)·ΔT²，本场景 ΔT≤30 K）：
方差 **0.017 K²**，可忽略。W4 式补精确幂次几乎无效（复算文档 §3：
加 q_int·P^(−1.4) 列仅 4.458→4.152）——缺口在 **h 调制与反馈极点**，
不在 P 幂次插值。

### 4.3 为什么 span(B) 在数学上够不到

B 库 = {Q^a·P^b : a∈{0,1}, b∈{1,−1,−1/2}}——对 h 依赖恒为零、加性可分结构。
目标方向要求 {g(Q,h,T_inf,P)·P^(−0.7)} 且 g 含 P 依赖的有理极点——无穷维
流形，不在任何有限单项式张成内。两列修复之所以有效，是因为第二列
q_int^LF/(1+hL/k_nom)·P^(−0.7) 恰好承载反馈极点的一阶（Taylor）结构。

### 4.4 交叉方程（修正）

```
R_PWL(n) ≈ δ² + b²(λ̂) + est(n) = 7.2 + b² + O(1/n)
R_GP(n)  ≈ est_GP(n)           = C·n^(−2s/(2s+4))，d=4
```

n=120 处：PWL 超额 13.25 ≈ 7.2 + 6；GP 超额 11.98（纯 est）。
**GP 的估计误差曲线在 n≈90–100 穿过"PWL 类偏置 + 协议项"的合成地板**——
失守是两条曲线相交，不是 PWL 退化。

### 4.5 v1 数字为何失真（教训记录）

- δ²=12.249：v1 投影用的 H 只有 θ 组 4 列（θ·[1,Q,Q²,Q/h]），漏掉真实 H 的
  1/h、T_inf、T_inf/h 三个方向——这些正是拟合对流有理结构的主力，
  被人为记入"类偏置"。复算文档用"4 列 B"反向逼近 12.25 是巧合性近似，
  两种解释指向同一事实：v1 的"类"被收窄；
- D=0.331：v1 分解脚本中 qint 取自高保真求解器（含 R_c 反馈的 P 依赖
  通量），违背 v1 自述的"低保真免费"工程前提；LF 口径真实水平 4.5–5.5。

## 5. 原因二（协议性，并行主战场）：正则平移 + 估计误差 ≈ 6 K²

### 5.1 机制（与 v1 相同）

惩罚估计量 β̂(λ) = argmin R_n(β) + λ·Ω(β)。总体极限下隐函数定理给出
β∞(λ) − β* = −λ·[∇²R(β*)]⁻¹∇Ω(β*) + O(λ²) ⇒ b²(λ) 与 n 无关，
仅 λ(n)→0 可消除。1-SE 规则：λ̂ = max{λ : MSE_val(λ) ≤ min + SE}；
@120 档 n_val=36，SE ≈ σ²·√(2/36) ≈ 4.8 K² ≫ 相邻 λ 臂 MSE 差（1–2 K²）
⇒ 选择集恒含最强物理权重 ⇒ **λ̂=10 不随 n 衰减**（实测 @120 仍 7/10 批
选 10.0）⇒ 正则平移常驻。

### 5.2 量级（v2 修正）

修正 δ² 后总账要求 b²+est ≈ 13.25 − 7.2 ≈ **6 K²**，与以下独立核算自洽：

- est ≈ σ²·p_eff/n = 20.2×13/84 ≈ 3.1 K²（17 列标准化特征、有效秩 ~13）；
- 剩余 ~3 K² 为正则平移 b²(λ̂=10) + L1/group 惩罚的收缩偏置；
- 逐批对照：@120 选 λ=0.1 的 3 批均值 MSE 32.39，选 λ=10 的 7 批 34.05，
  方向一致（受批间方差掩盖，非决定性，但与 b² 量级相容）。

**v1 将此项降级为"~1 K² 二阶效应"的判定撤回。** 协议项与基函数缺口
同等量级，是类偏置修复之后的下一个主战场。

## 7. 归因结论（v2）：基函数占一半，协议占一半

PWL @120 超额 13.25 K² 的归属：

| 成分 | 量级 (K²) | 占比 | 性质 |
|---|---:|---:|---|
| B 库缺失接触乘积方向（含反馈极点结构） | ≈6.8 | ~51% | 基函数（可修复：两列 → 0.44） |
| H/B 残余截断 + k(T) + 高阶交互 | ≈0.4 | ~3% | 基函数（量微） |
| 估计误差 est（p_eff≈13, n=84） | ≈3 | ~23% | 样本量固有 |
| 正则平移 b²(λ̂) + 收缩偏置 | ≈3 | ~23% | 选参协议（可修复：λ 衰减/1-SE 修订） |

对"是否归因到基函数"的回答：**是，但只是一半**——约 54% 的超额误差
来自基函数缺口（其中 51 个百分点可用两列低保真免费特征直接修复），
其余约 46% 来自估计误差与协议性正则平移，二者同等量级、需并行推进。

不归因于基函数的部分：θ 不可识别（物理结构：k 与 R_c 串联、等效 k 在盒外；
且 rank(H)=7、θ 不进标签拟合张成，不直接造成精度损失）；协议项。

### 归因线索的收敛（含 v1 教训）

H/B 列空间重叠 → W1 降为次要 → k(T) 非线性 → 实测 0.017 K² 否决 →
v1 精确分解落回基函数但口径失真（H 缺列虚高 δ²、HF 通量冒充 LF 免费列）→
**v2 定稿：缺口确认为 h 调制 + 通量反馈的乘积结构，占一半；协议项占另一半。**
W1 正交化、W2 冻结、W10 刷新未改变排序的原因：三者既未触碰 B 对该方向
的覆盖，也未触碰选参协议。

## 8. 修正后的预测与实验方案

### 8.1 两列低保真免费修复（推荐，已经两路独立复算）

```
B 新增两列：  col1 = q_int^LF(k_nominal)·P^(−0.7)
              col2 = q_int^LF(k_nominal)/(1 + hL/k_nominal)·P^(−0.7)
q_int^LF = QL/2 − k·a_LF，a_LF 按 heat.py 闭式逐点计算（k_nominal=25）
```

- 两列只依赖 (Q, h, T_inf) 与常数 k_nominal，与 `heat_b_raw(x_ph, x_pr)`
  签名兼容；col2 承载通量反馈极点的一阶结构；
- **已验证效果**：参数类偏置 δ² 7.2 → **0.435–0.458 K²**（3 种子）；
- PWL @120 预期：MSE ≈ σ² + 0.44 + (b²+est≈6) ≈ **26–27（RMSE ≈ 5.1–5.2）**；
- 注意：与单列版（δ²→5.4）拉不开差距——**协议项不处理，修复红利只能
  兑现一部分**，这是与 v1 预测（22–23）的本质区别。

### 8.2 实验配置与验收（修正）

1. 实现 `heat_v3_qint` spec 变体（两列版），配置 `configs/heat_v3_qint.yaml`
   沿用 `heat_refresh.yaml`，跑 default 规模（10 批 × 12 档 × 36 候选）；
2. **验收标准**：@120 档 PWL RMSE < Physics-GP（5.53）即锚点 6 通过；
   @10 档优势不退化（当前 +1.69 K）；
3. 监控：θ 撞界率、无效候选率按首版口径（新列改变 d/θ 争抢结构；
   刷新臂无效候选率已 26.2%，需防恶化）。

### 8.3 并行工作项：协议项量化与修复

- λ_physics 网格向低端扩展 + 大样本档禁用/修订 1-SE 规则的对照实验，
