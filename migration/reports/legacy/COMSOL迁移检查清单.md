# PWL 迁移至 COMSOL 代理模型的检查清单

> 更新日期：2026-07-30  
> 状态：迁移评审清单 v1  
> 适用对象：将当前 PWL 复现框架迁移到 COMSOL 仿真代理模型或新物理场景  
> 关联文档：`当前差值统一解释.md`

---

## 1. 核心判断

当前复现结果与论文结果之间的差值，主要来源于当前仿真任务与作者原实验设置之间的结构性不一致。该差值与论文式（9）–（11）所定义的物理系统、输入分布、`H/B` 基函数、噪声尺度和奇点处理强绑定。

因此，在迁移到 COMSOL 代理模型时，应区分两类因素：

1. **不可继承因素**：当前论文复现中的具体差值来源，不应默认带入新场景；
2. **方法共性风险**：PWL 对基函数、弱标签质量、输入覆盖和参数可识别性的依赖，会以新的形式继续存在。

本清单用于判断：哪些问题可以认为已经随场景切换而重置，哪些问题必须在 COMSOL 迁移中重新验证。

## 2. 不可继承因素清单

| 检查项 | 当前复现中的表现形式 | 迁移后的判断 | 状态 |
|---|---|---|---|
| 论文 120 标签 RMSE 差值 | 当前结果接近当前噪声下限，但高于论文数值 | 该具体数值差不继承；COMSOL 场景需重新建立噪声下限 | [ ] 已确认 |
| 论文 IV-A/IV-B/IV-C 曲线差异 | 与论文样本量、物理精度、监督交点不一致 | 不用于预测新场景学习曲线；新场景重新做基准实验 | [ ] 已确认 |
| 当前 25 维 `H` | 围绕 `x1,x2,x3,S(x3),theta1,theta2` 手工构造 | 不直接迁移；必须根据 COMSOL 物理机理重新设计 | [ ] 已确认 |
| 当前紧凑/扩展 `B` | 围绕 `x4,x5` 及式（10）（11）构造 | 不直接迁移；必须根据新差异结构重新设计 | [ ] 已确认 |
| `x4/x5`、`x5/x4` 奇点 | 当前比例项需要专门的近零处理 | 若新场景无比例项，则该具体风险不继承；若仍存在，需重新定义安全规则 | [ ] 已确认 |
| 当前输入分布 `Sigma_x` | 为满足论文 0.85 相关性目标而设 | 不继承；新输入分布由 COMSOL 工况与实验条件决定 | [ ] 已确认 |
| 当前物理噪声比例 | `physics_noise_fraction=0.25` 是仿真实验假设 | 不继承；替换为 COMSOL 代理模型的独立验证误差 | [ ] 已确认 |
| 当前真实 `theta=(0.7,0.5)` | 论文仿真专用参数设定 | 不继承；新场景需确认是否存在校准参数及其物理含义 | [ ] 已确认 |
| 当前 `theta` 边界命中现象 | 反映当前 `H` 参数化与仿真任务不匹配 | 该具体现象不继承；但新 `theta` 仍需检查边界命中 | [ ] 已确认 |
| 当前论文对照结论 | “结构性复现，不是绝对数值复现” | 迁移报告不应再把论文数值作为直接目标 | [ ] 已确认 |

### 小结

可统一表述为：

> 当前论文复现差值的具体数值和具体诱因不随迁移自动继承。迁移后应把 COMSOL 代理模型场景视为新的任务，重新建立数据分布、特征库、噪声尺度和评价基线。

## 3. 方法共性风险清单

以下风险不会以当前的具体形式直接继承，但会以新场景对应形式继续影响 PWL 性能。

### 3.1 COMSOL 代理模型保真度

| 检查项 | 必查问题 | 建议证据 | 状态 |
|---|---|---|---|
| 训练/测试划分 | 是否使用独立 COMSOL 样本评估代理模型 | 训练集、验证集、测试集划分记录 | [ ] |
| 点预测误差 | 代理模型相对 COMSOL 的 RMSE、MAE、最大误差是否可接受 | 独立测试集误差表 | [ ] |
| 决定系数 | 代理模型是否解释了主要输出变化 | 独立测试集 R² | [ ] |
| 残差结构 | 残差是否存在明显趋势、异方差或区域偏差 | 残差图、分区误差表 | [ ] |
| 外推风险 | PWL 使用区域是否超出代理模型训练区域 | 输入范围、距离度量、外推标记 | [ ] |
| 不确定度 | 代理模型是否提供预测方差或置信区间 | 方差输出、校准曲线或误差区间 | [ ] |

**判断规则**：如果代理模型本身不能稳定复现 COMSOL 输出，则不应把其输出直接视为可靠弱标签。

## 4. 代码迁移检查清单

当前代码已有外部 `physics_model` 接口，但仍是论文仿真专用实现。正式迁移前建议完成以下改造。

| 改造项 | 当前状态 | 迁移要求 | 状态 |

| 输入维度 | 固定 `x_ph=3`、`x_pr=2` | 从配置或 `FeatureSpec` 读取维度 | [ ] |

## 6. 建议的 Go / No-Go 判定

### 可以进入 PWL 迁移开发（Go）

满足以下条件时，可以认为具备正式迁移基础：

- [ ] COMSOL 代理模型在独立测试集上达到项目设定精度；
- [ ] 新场景的数据契约已经明确，包括 `x_ph`、`x_pr`、`y`、`weak_x_ph`、`weak_y`；
- [ ] 新 `H/B` 已有物理或经验依据；
- [ ] `theta` 是否存在、维度、边界和更新方式已经明确；
- [ ] 当前代码的固定维度限制已完成泛化或已有明确改造计划；
- [ ] 已设置独立真实标签测试集，不用于训练或调参。

### 只适合小规模试点（Pilot）

存在以下任一情况时，只建议先做小规模可行性试验：

- [ ] 代理模型误差接近真实标签中的主要变化幅度；
- [ ] 弱标签覆盖区域与真实标签区域存在明显偏移；
- [ ] `H/B` 尚无明确设计，只能暂时沿用通用多项式；
- [ ] `theta` 是否存在尚不明确；
- [ ] COMSOL 代理没有不确定度输出，且存在外推需求。

### 不应声称 PWL 已迁移成功（No-Go）

出现以下任一情况时，不应把当前结果表述为“模型已成功迁移”：

- [ ] 未验证 COMSOL 代理模型保真度；
- [ ] 仍直接使用论文仿真的 25 维 `H` 或比例型 `B`，但没有新场景依据；
- [ ] 未用独立真实标签测试；
- [ ] 仅把 `physics_model` 替换为黑盒代理，却声称 `theta` 已进入完整闭环校准；
- [ ] 新场景输入维度不满足当前代码的固定维度约束；
- [ ] PWL 结果不优于直接代理预测或简单残差模型。

## 7. 迁移报告中的推荐表述

建议后续报告统一使用以下表述：

> 当前论文复现差值的主要来源与论文仿真物理模型、未知作者 `H/B`、输入分布、噪声尺度和奇点处理强绑定，因此这些具体差值不应直接继承到 COMSOL 新场景。迁移后，PWL 的性能需要重新由 COMSOL 代理保真度、新 `H/B` 设计、弱标签覆盖性、校准参数可识别性和独立真实标签测试共同决定。当前代码具备 PWL 框架和外部物理模型接口，但在正式迁移前仍需解除固定输入维度、固定二维校准参数和仿真专用特征库的限制。

一句话版本：

> **论文复现差值不会原样带入 COMSOL 场景，但 PWL 对物理弱标签、特征库和参数化的敏感性仍必须在新场景中重新验证。**

## 8. 签字式最终检查

- [ ] 我没有把当前论文复现差值当作 COMSOL 场景的预测误差；

- [ ] 我已经为新物理场景重新设计 `H` 和 `B`；
- [ ] 我已经明确 `theta` 是否存在、如何约束、是否参与更新；
- [ ] 我已经确认弱标签覆盖真实标签和未来预测区域；
- [ ] 我已经解除或绕开当前代码的固定维度限制；
- [ ] 我已经与直接代理、纯监督和残差校正基线比较；
- [ ] 我已经用独立真实标签报告最终性能；
